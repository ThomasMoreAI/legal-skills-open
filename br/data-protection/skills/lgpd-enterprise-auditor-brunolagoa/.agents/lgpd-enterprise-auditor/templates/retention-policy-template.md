# Modelo — política de retenção e eliminação

> Conferido pelos itens `GV-04` e `GV-12` a `GV-14` do catálogo. Base: arts. 15 e 16 da LGPD. Terminado o tratamento, os dados são eliminados; conservar só é permitido nas hipóteses do art. 16.

## 1. Regras gerais
- o tratamento termina quando a finalidade é alcançada, o prazo acaba, o titular revoga o consentimento ou a ANPD determina (art. 15);
- cada categoria de dado tem prazo e responsável;
- quem é operador segue os prazos instruídos pelo controlador.

## 2. Prazos por categoria
| Categoria de dado | Finalidade | Prazo de retenção | Hipótese do art. 16 para conservar depois do fim do tratamento | Forma de eliminação ou anonimização | Responsável |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

Hipóteses do art. 16: cumprimento de obrigação legal ou regulatória (I); estudo por órgão de pesquisa, com anonimização sempre que possível (II); transferência a terceiro, respeitados os requisitos de tratamento (III); uso exclusivo do controlador, com dados anonimizados e sem acesso de terceiros (IV).

## 3. Retenções legais
| Dado | Norma | Prazo |
|---|---|---|
| Registros de acesso a aplicações de internet | Marco Civil da Internet, art. 15 | 6 meses |
|  |  |  |

Completar com as retenções fiscais, trabalhistas e setoriais que se aplicarem, cada uma com a norma e o prazo.

## 4. Eliminação
- execução automática ao fim do prazo, sempre que possível;
- alcance: banco principal, réplicas, backups e operadores;
- registro de cada descarte (o quê, quando, por quem).
