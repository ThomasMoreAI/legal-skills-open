# PARTE IX — VOCABULARIO JURÍDICO DE ÉLITE (MEXICANO)

## 9.1 Verbos de Alta Precisión para Escritos Mexicanos

| Verbo | Aplicación |
|-------|-------------|
| **fractura** | Incumplimiento grave de estándar jurídico |
| **quebranta** | Violación de norma imperativa |
| **infringe** | Incumplimiento de disposición legal |
| **transgrede** | Violación de garantía constitucional |
| **vulnera** | Lesión a derechos fundamentales |
| **subsume** | Encuadramiento de hechos en norma |
| **acredita** | Prueba de un hecho |
| **evidencia** | Demostración ostensible de un hecho |
| **constata** | Verificación de un hecho documentado |
| **impone** | Obligación ineludible del juzgador |
| **exige** | Imperativo legal o jurisprudencial |
| **deviene** | Se convierte, llega a ser |
| **dicta** | Pronuncia una resolución |
| **establece** | Fija criterio jurisprudencial |
| **sostiene** | Mantiene posición jurisprudencial |

---

## 9.2 Latinismos de Uso Forense Mexicano

| Latinismo | Significado y Uso |
|-----------|-------------------|
| **sub judice** | Bajo conocimiento del juez; el asunto que se litiga |
| **a quo** | El juez de primera instancia (en el recurso) |
| **ad quem** | El tribunal de alzada (en el recurso) |
| **litis** | La controversia planteada |
| **in limine** | Al umbral del proceso; in limine litis |
| **ex officio** | De oficio, sin petición de parte |
| **iter criminis** | Camino del delito (materia penal) |
| **non bis in idem** | No dos veces por lo mismo |
| **per se** | Por sí mismo; en sí |
| **ultra petita** | Más allá de lo pedido (vicio de la sentencia) |
| **erga omnes** | Con efectos frente a todos |
| **ex ante** | Antes del hecho; a priori |
| **ex post** | Después del hecho; a posteriori |
| **sui géneris** | De su género; único en su clase |
| **pro bono** | Por el bien público |

## 9.3 Frases de Apertura para Fundamentos de Derecho

```
* "Tal y como lo ha sostenido de manera reiterada el Pleno / 
  la Primera Sala de la Suprema Corte de Justicia de la Nación..."

* "La jurisprudencia firme del Poder Judicial de la Federación 
  ha establecido con claridad meridiana que..."

* "En perfecta congruencia con el criterio del Alto Tribunal..."

* "El Tribunal Colegiado del Cuarto Circuito, en criterio que resulta 
  aplicable al presente asunto, ha determinado que..."

* "Resulta palmario que, en términos del artículo [X] del 
  [ordenamiento]..."

* "Conforme a lo establecido en la jurisprudencia de rubro 
  '[RUBRO]'..."

* "A mayor abundamiento, la normativa aplicable prevista en 
  el artículo [X] establece que..."

* "De conformidad con los principios más elementales del ordenamiento 
  jurídico mexicano..."
```

---

## 9.4 Frases de Cierre para Bloques de Subsunción

```
* "Por tanto, no cabe sino concluir que..."

* "La subsunción es inevitable: al concurrir [elementos], 
  esta H. Autoridad deberá..."

* "De lo anterior se infiere, sin posibilidad de interpretación 
  contraria, que..."

* "En consecuencia, y atendiendo al principio de legalidad que rige 
  la actuación de las autoridades jurisdiccionales, el H. Juzgado 
  deberá declarar..."

* "El análisis conjunto de los hechos probados y de los criterios 
  jurisprudenciales citados conduce, de forma ineluctable, a la 
  conclusión de que..."

* "No es posible llegar a otra conclusión que la de que..."

* "Resulta evidente que [conclusión]..."

* "Advierto que la subsunción propuesta es la única compatible 
  con [norma/jurisprudencia]..."
```

## 9.5 Expresiones PROHIBIDAS y Sus Sustitutos

| PROHIBIDO | Sustituir por |
|-----------|---------------|
| "creo que / me parece" | "Resulta palmario que" / "Conforme a..." |
| "dicho" (pronombre) | "tal" / "el referido" / "el antes mencionado" |
| "el mismo / la misma" | Repetir sustantivo o usar "aquel" |
| "proceder a" | "proceder" / "realizar" / "ejecutar" |
| "en aras de" | "en beneficio de" / "en favor de" |
| "toda vez que" | "en virtud de que" / "dado que" / "puesto que" |
| "quizás / tal vez" | Eliminar en Fundamentos; usar en análisis adversario |
| "podría" (en propia tesis) | Suprimir o usar afirmación categórica |
