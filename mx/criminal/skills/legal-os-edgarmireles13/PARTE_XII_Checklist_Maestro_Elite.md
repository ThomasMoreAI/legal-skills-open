# PARTE XII — CHECKLIST MAESTRO DE ÉLITE

## 12.1 Pre-Redacción

- [ ] ¿Se construyó la Matriz de Hechos con fechas, documentos y números?
- [ ] ¿Se verificó la competencia del órgano jurisdiccional?
- [ ] ¿Se verificaron los plazos procesales y de prescripción?
- [ ] ¿Se identificó el tipo de procedimiento correcto?
- [ ] ¿Se localizaron las tesis jurisprudenciales aplicables en el SJF?
- [ ] ¿Se verificó la competencia territorial correcta?
- [ ] ¿Se identificaron todos los documentos acreditatorios disponibles?
- [ ] ¿Se realizó análisis de riesgo procesal preliminar?

---

## 12.2 Durante la Redacción

### Encabezamiento

- [ ] ¿El encabezamiento identifica correctamente al juzgado / tribunal?
- [ ] ¿Se incluyó el número del juzgado (si aplica)?
- [ ] ¿Se identificó el distrito judicial (si aplica)?
- [ ] ¿Se escribió "P R E S E N T E" con espacios?

### Hechos

- [ ] ¿Los Hechos están numerados de forma secuencial?
- [ ] ¿Cada Hecho tiene fecha específica (DD/MM/AAAA)?
- [ ] ¿Cada Hecho tiene lugar identificable?
- [ ] ¿Cada Hecho cita el Documento que lo acredita?
- [ ] ¿Los Hechos están en orden cronológico?
- [ ] ¿No hay argumentación jurídica en los Hechos (solo narrativa)?
- [ ] ¿La narración es precisa y evita generalizaciones?

### Fundamentos de Derecho

- [ ] ¿Cada Fundamento aplica el método DOCTRINA → HECHOS → CONCLUSIÓN?
- [ ] ¿Las citas del SJF incluyen: rubro, número de tesis, época, libro/tomo, fecha, página, registro?
- [ ] ¿Cada cita se conecta con al menos un Hecho numerado de la demanda?
- [ ] ¿Se usan los conectores de subsunción correctos (§ 4.4)?
- [ ] ¿Hay conclusión jurídica tras cada bloque de subsunción?
- [ ] ¿No hay frases dubitativas ("podría", "quizás", "probablemente")?
- [ ] ¿El tono es categórico en toda la extensión?

### Petitorio

- [ ] ¿El petitorio es claro en una lectura rápida?
- [ ] ¿Cada petición es precisa y no ambigua?
- [ ] ¿El petitorio es congruente con los Hechos y Fundamentos?
- [ ] ¿No hay peticiones ultra petita (más allá de lo pedido)?
- [ ] ¿Las cuantías están correctamente calculadas?

### Pruebas

- [ ] ¿El ofrecimiento de pruebas clasifica correctamente cada medio probatorio?
- [ ] ¿Cada prueba está relacionada con el (los) Hecho(s) que acredita?
- [ ] ¿Se utilizan los números de Hechos en el ofrecimiento de pruebas?
- [ ] ¿Las pruebas documentales citan los expedientes o referencias correctas?
- [ ] ¿Las pruebas periciales especifican la materia correctamente?
- [ ] ¿Las pruebas testimoniales identifican a los testigos (nombre, domicilio)?

---

## 12.3 Post-Redacción

### Estilo y Lenguaje

- [ ] ¿Se eliminaron todos los arcaísmos (§ 1.3)?
- [ ] ¿Se eliminaron las expresiones prohibidas (§ 1.3)?
- [ ] ¿El escrito no contiene "dicho" como pronombre?
- [ ] ¿No hay "el mismo" o "la misma" como pronombres?
- [ ] ¿No hay "proceder a" (se usa "proceder")?
- [ ] ¿No hay "toda vez que" sin justificación (se usa "en virtud de que")?
- [ ] ¿El vocabulario es de élite forense mexicana (§ 9.1, 9.2)?
- [ ] ¿Las frases de apertura y cierre son de impacto (§ 9.3, 9.4)?

### Verificación Jurídica

- [ ] ¿Se verificaron TODAS las tesis citadas en sjf2.scjn.gob.mx?
- [ ] ¿Los números de registro SJF son exactos?
- [ ] ¿Los datos de publicación coinciden (libro, tomo, página, fecha)?
- [ ] ¿Las tesis citadas están vigentes y no han sido revocadas?
- [ ] ¿La jerarquía de jurisprudencia es correcta (§ 4.1)?

### Congruencia

- [ ] ¿No hay contradiccion entre Hechos y Fundamentos?
- [ ] ¿No hay contradicción entre Fundamentos?
- [ ] ¿El Petitorio se desprendetornaturalmente de Hechos + Fundamentos?
- [ ] ¿Los números de Hechos citados en Fundamentos existen en la sección de Hechos?
- [ ] ¿Los números de Documentos en Fundamentos coinciden con el ofrecimiento de pruebas?

### Formato y Presentación

- [ ] ¿El documento tiene el formato correcto para México (papel carta, márgenes)?
- [ ] ¿La fuente es Times New Roman 12pt o Arial 12pt?
- [ ] ¿Los márgenes son mínimo 2.5 cm?
- [ ] ¿Se adjuntan TODOS los documentos mencionados en los Hechos?
- [ ] ¿La firma y la cédula profesional del licenciado están correctamente asentadas?
- [ ] ¿La fecha del escrito es correcta?
- [ ] ¿El nombre del despacho / logo están en el encabezamiento?

### Última Revisión

- [ ] ¿Se realizó una última lectura de coherencia lógica completa?
- [ ] ¿El escrito puede leerse de forma independiente sin archivos adjuntos?
- [ ] ¿No hay errores ortográficos o de puntuación?
- [ ] ¿Las abreviaturas son estándar y consistentes?
- [ ] ¿La numeración de Hechos, Fundamentos y Peticiones es consistente?

---

## 12.4 Checklist Específico por Tipo de Escrito

### Para Demandas Civiles

- [ ] ¿Se verificó que el demandado tiene domicilio conocido?
- [ ] ¿Se indicó correctamente el primer domicilio para notificaciones?
- [ ] ¿La demanda se presentó dentro de plazos de prescripción?
- [ ] ¿La competencia territorial es correcta (§ 5.1.3)?

### Para Amparos Indirectos

- [ ] ¿Se identificaron correctamente las autoridades (Ordenadora y Ejecutora)?
- [ ] ¿Cada Concepto de Violación es autosuficiente?
- [ ] ¿Se solicitó suspensión provisional y definitiva?
- [ ] ¿El perjuicio de difícil reparación está acreditado?

### Para Amparos Directos (contra sentencias)

- [ ] ¿Se identificó la sentencia combatida con precisión?
- [ ] ¿Cada Agravio ataca la motivación del juez de forma directa?
- [ ] ¿No hay agravios genéricos sin conexión con la sentencia?

### Para Recursos de Apelación

- [ ] ¿Se indicó la resolución impugnada con referencia a expediente y fecha?
- [ ] ¿Cada Agravio es autonómico e independiente?
- [ ] ¿No hay agravios que reiteren lo resuelto favorablemente?
