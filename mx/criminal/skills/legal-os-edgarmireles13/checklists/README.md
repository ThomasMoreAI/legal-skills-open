# Checklists de Redacción Jurídica - LEGAL-OS

Guías prácticas y checklists de validación para redacción de documentos jurídicos de élite en el contexto mexicano.

## 📋 Contenido

```
checklists/
├── guia_redaccion_elite.md              # Estándares de redacción jurídica de élite
├── demanda_laboral_checklist.md         # Validación específica para demandas laborales
├── escrito_queja_checklist.md           # Validación para escritos de queja
├── validador_argumentos.md              # Validación de argumentación jurídica
├── amparo_checklist.md                  # Validación de escritos de amparo
└── README.md                            # Este archivo
```

## 🎯 Objetivo

Proporcionar herramientas de validación y mejora para litigantes mexicanos, asegurando que cada documento cumpla con:

1. **Estándares de excelencia jurídica**
2. **Normativa procesal mexicana**
3. **Mejores prácticas de argumentación**
4. **Claridad y precisión técnica**
5. **Completitud de elementos esenciales**

## 📚 Cómo usar estos checklists

Cada checklist incluye:
- ✅ Items de validación específicos
- 📝 Ejemplos de redacción correcta/incorrecta
- 🔗 Referencias normativas
- 💡 Tips de mejora
- ⚠️ Errores comunes a evitar

Integración con **mireles-docs**: Los checklists se ejecutan automáticamente durante la generación de documentos, marcando advertencias y sugerencias.
