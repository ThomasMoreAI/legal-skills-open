# PARTE XI — INTEGRACIÓN DE SKILLS: FLUJO DE TRABAJO COMPLETO

## 11.1 Orden de Ejecución Recomendado para Escritos

```
PASO 1 — ANÁLISIS DEL CASO
│  ✅ Leer todos los documentos del cliente
│  ✅ Construir la MATRIZ DE HECHOS (§ 8.1)
│  ✅ Identificar la acción procesal correcta
│  ✅ Verificar plazos y prescripción
└────────────────────────────────────────

PASO 2 — INVESTIGACIÓN NORMATIVA Y JURISPRUDENCIAL
│  ✅ Identificar normas del CCNL / CPCNL / C.Co. aplicables
│  ✅ Buscar tesis en SJF (sjf2.scjn.gob.mx)
│  ✅ Verificar vigencia y jerarquía de cada tesis
│  ✅ Construir la MATRIZ HECHOS-DOCTRINA (§ 8.1)
└────────────────────────────────────────

PASO 3 — REDACCIÓN DEL ESCRITO
│  ✅ Encabezamiento correcto (§ 3.3)
│  ✅ Hechos: cronológicos, numerados, documentados
│  ✅ Fundamentos: subsunción completa por patrón (§ 8.2)
│  ✅ Petitorio: preciso y congruente
│  ✅ Pruebas: clasificadas y relacionadas con hechos
└────────────────────────────────────────

PASO 4 — REVISIÓN DE CALIDAD
│  ✅ Checklist completo (§ 8.1, Fase 4)
│  ✅ Verificación de citas del SJF
│  ✅ Revisión de estilo (§ 1.3)
│  ✅ Congruencia petitorio-hechos-fundamentos
└────────────────────────────────────────

PASO 5 — GENERACIÓN DEL DOCUMENTO
│  ✅ Formato Word profesional (skill docx)
│  ✅ Papel tamaño carta (México) — 12240 x 15840 DXA
│  ✅ Fuente: Times New Roman 12pt o Arial 12pt
│  ✅ Márgenes mínimos 2.5 cm (práctica NL)
└────────────────────────────────────────
```

## 11.2 Advertencias sobre el Uso de Inteligencia Artificial en la Práctica Jurídica

### Responsabilidad del Profesional

La jurisprudencia citada en cualquier escrito generado con la asistencia de este manual **debe ser verificada de forma independiente** por el licenciado en ciencias jurídicas antes de presentar el escrito ante cualquier órgano jurisdiccional.

**La inteligencia artificial puede cometer errores en:**
- Números de registro SJF
- Datos de publicación
- Vigencia de tesis
- Interpretación de jurisprudencia

**El profesional es, en todo momento, el responsable técnico y ético del contenido del escrito.**

### Regla Práctica

Antes de presentar cualquier escrito, **verificar cada cita del SJF directamente en:**

```
https://sjf2.scjn.gob.mx
```

Introduce el número de registro o el rubro exacto.

### Validación de Datos

- ✅ Número de registro correcto
- ✅ Tribunal emisor identificado con precisión
- ✅ Época correcta
- ✅ Libro/Tomo/Página coinciden
- ✅ Rubro idéntico al citado
