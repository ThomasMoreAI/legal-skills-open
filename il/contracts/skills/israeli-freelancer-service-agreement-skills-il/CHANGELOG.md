# Changelog

All notable changes to this skill are documented here.

## [1.3.0] - 2026-09-15

### Added

- חובת מספר הקצאה בחשבונית מס מעל 5,000 ₪ לפני מע"מ, החל מ-1 ביוני 2026.
- טיפול באמצאות לפי סעיף 132 לחוק הפטנטים, מסירת קבצי מקור ורשימת רכיבי קוד פתוח, ובחירה מפורשת בסקריפט מי הבעלים של האמצאות.
- מצב לקוח זר בסקריפט, שמשמיט את מסגרת חוק מוסר תשלומים ומשאיר את שיעור המע"מ לרואה החשבון.
- אזהרה כשתמורה של עוסק פטור חוצה את תקרת העוסק הפטור לשנת 2026.

### Changed

- סעיף הקיזוז במקרה של סיווג מחדש נוסף רק לפי בקשה, והוסר המשפט שהתמורה גבוהה משכר עובד מקביל, שהיה ראיה נגד העצמאי.
- ריבית הפיגורים מנוסחת בהפניה לחוק פסיקת ריבית והצמדה.

### Fixed

- הוסרה הסתירה בעניין הזכות המוסרית: הסכמה לשינויים מוגדרים והסדר קרדיט במקום ויתור.

## [1.2.0] - 2026-08-09

### Added

- נוסף פרק "הבהרה משפטית" בראש SKILL.md ו-SKILL_HE.md, המפרט מה הכלי עושה, מה הוא אינו, ולאיזה בעל מקצוע מוסמך יש לפנות.

### Changed

- התיאור נפתח כעת בהבהרה קצרה, כך שהיא נראית גם בכרטיס ובתוצאות החיפוש.
