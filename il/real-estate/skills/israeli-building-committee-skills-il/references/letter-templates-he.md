# תבניות לוועד הבית

הטקסט נשלח בשם הכותבים עצמם (הדייר או חברי הוועד), לא בשם עורך דין, ואין להוסיף לו טיעון משפטי או איום בהליך.

כל התבניות הן טיוטה להתארגנות אישית בלבד (ראו ההבהרה המשפטית ב-SKILL_HE.md). הדיירים ממלאים ומתאימים אותן בעצמם. **אין כאן כתב תביעה**, ולא מנסחים כזה. שדות בסוגריים מרובעים ממלאים לפני שליחה.

## 1. הודעה לקבוצת הוואטסאפ

```
שלום שכנים
[נושא אחד, משפט אחד: למשל, הגיעו שלוש הצעות מחיר לאיטום הגג]
מה צריך מכם: [להצביע / לשלם / לפנות את חדר המדרגות] עד [תאריך].
החלוקה לפי [שטח הדירות, ברירת המחדל שבחוק המקרקעין / התקנון הרשום של הבית]. הטבלה המלאה: [קישור]
שאלות? בפרטי ל[שם], [טלפון].
```

כללים: נושא אחד להודעה. בלי שמות של חייבים. בלי הקלטות קוליות להחלטות, רק טקסט.

## 2. הזמנה לאסיפה כללית

```
הזמנה לאסיפה כללית של בעלי הדירות
בית משותף ברחוב [רחוב ומספר], [עיר]

מועד: יום [יום], [תאריך], בשעה [שעה]
מקום: [לובי / דירה / זום, עם קישור]

סדר היום:
1. בחירת יושב ראש ומזכיר לאסיפה
2. [דיווח כספי של הגזבר]
3. [אישור תקציב ודמי ועד לשנה הקרובה]
4. [בחירת ועד]
5. [נושא נוסף]

אם לא יהיה מניין חוקי בשעה שנקבעה, האסיפה תתקיים באותו יום בשעה [שעה מאוחרת יותר], ותהיה חוקית בכל מספר משתתפים.

בעל דירה שלא יכול להגיע רשאי למנות בא כוח בכתב חתום (נוסח למטה), שיימסר לוועד לפני פתיחת האסיפה.
בעל דירה שרוצה להוסיף נושא לסדר היום צריך להודיע לכל בעלי הדירות לפחות יומיים לפני האסיפה.

בברכה,
ועד הבית
תאריך פרסום ההודעה: [תאריך]
```

בדיקות לפני פרסום (לפי התקנון המצוי, אם אין תקנון רשום אחר): הודעה לכל בעלי הדירות ארבעה ימים לפחות מראש; הודעה שנתלתה בלובי נחשבת כנמסרה יום אחרי התלייה, אז תלו אותה יום אחד מוקדם יותר; סדר היום מפורט.

**כתב מינוי בא כוח:**
```
אני, [שם], בעל/ת דירה [מספר] בבית המשותף ברחוב [כתובת], ממנה את [שם] לייצג אותי ולהצביע בשמי באסיפה הכללית ביום [תאריך].
חתימה: ________ תאריך: ________
```
אם לדירה כמה בעלים, כולם חותמים על מינוי של נציג אחד.

## 3. פרוטוקול אסיפה

```
פרוטוקול אסיפה כללית, בית משותף [כתובת]
תאריך: [תאריך] שעת פתיחה: [שעה]
יושב/ת ראש: [שם] מזכיר/ה: [שם]

נוכחות (דירה / שם / בעצמו או בא כוח):
[1 / ... / בעצמו]
[2 / ... / בא כוח: ...]
סה"כ דירות מיוצגות: [X] מתוך [Y]. מניין: [חוקי / נפתחה בשעה החלופית]

נושא 1: [כותרת]
דיון בקצרה: [2 עד 3 שורות, בלי ציטוטים אישיים]
הצבעה: בעד [X] נגד [Y] נמנעים [Z]
החלטה: [נוסח מדויק שנרשם בספר ההחלטות]

נושא 2: ...

האסיפה ננעלה בשעה [שעה].
חתימת יו"ר: ________ חתימת מזכיר/ה: ________
```

אחרי האסיפה: להעתיק את נוסח ההחלטות לספר ההחלטות, ולשלוח את הפרוטוקול לכל בעלי הדירות.

## 4. טבלת השוואת הצעות מחיר

| פרמטר | הצעה א | הצעה ב | הצעה ג |
|---|---|---|---|
| שם הספק, ח"פ/עוסק | | | |
| היקף העבודה המדויק | | | |
| חומרים ומפרט (למשל סוג יריעת איטום, מספר שכבות צבע) | | | |
| אחריות: כמה זמן ועל מה | | | |
| לוח תשלומים (מקדמה, אבני דרך, תשלום אחרי סיום) | | | |
| ביטוח צד שלישי וביטוח עבודות | | | |
| רישיון או הסמכה רלוונטיים | | | |
| ממליצים מבניינים דומים | | | |
| מועד התחלה ומשך העבודה | | | |
| מחיר כולל מע"מ | | | |
| חלק כל דירה (לפי טבלת השטחים) | | | |

לשירות מעלית הוסיפו: זמן תגובה לתקלה, מה כלול בחוזה ומה בתשלום נוסף, ותקופת ההתקשרות. לצביעה: הכנת קירות ותיקוני טיח. השוו רק הצעות עם אותו היקף עבודה.

## 5. סיכום תקציב שנתי לדיירים

```
דוח כספי שנתי, ועד הבית [כתובת], שנת [שנה]

יתרת פתיחה בחשבון הבנק ב-1 בינואר: [סכום]

הכנסות:
- דמי ועד שנגבו: [סכום] (פירוט לפי דירה בנספח, בלי לפרסם בקבוצה)
- הכנסות אחרות: [סכום]

הוצאות (כל שורה עם מספר חשבונית):
- ניקיון: [סכום]
- חשמל רכוש משותף: [סכום]
- שירות מעלית: [סכום]
- תיקונים: [פירוט]
- אחר: [פירוט]

יתרת סגירה ב-31 בדצמבר: [סכום]
חובות פתוחים של דירות: [סכום כולל]
פנקס ההכנסות וההוצאות, החשבוניות והקבלות פתוחים לעיון כל בעל דירה בתיאום עם הגזבר.
```

## 6. דמי ועד שלא שולמו

**שלב א, תזכורת ידידותית (בפרטי):**
```
היי [שם], מה שלומך?
רק תזכורת קטנה שדמי הוועד של [חודשים] עוד לא עברו, סך הכול [סכום].
אפשר להעביר ל[פרטי חשבון הבית המשותף]. אם יש טעות או קושי, דבר/י איתי ונסדר.
תודה, [שם], ועד הבית
```

**שלב ב, דרישה בכתב מהוועד:**
```
[תאריך]
לכבוד [שם בעל הדירה], בעל/ת דירה [מספר], [כתובת]

בנושא: דמי ועד בית שלא שולמו

1. לפי החלטת האסיפה הכללית מיום [תאריך], שנרשמה בספר ההחלטות, דמי הוועד לדירתך הם [סכום] לחודש, לפי חלק הדירה בשטח (פירוט מצורף).
2. לפי רישומי הגזבר, לא שולמו דמי הוועד לחודשים [חודשים], סך הכול [סכום]. פירוט חודשי מצורף.
3. פנינו אליך בנושא ב-[תאריכים ואמצעי הפנייה].
4. נבקש להסדיר את התשלום עד [תאריך], לחשבון [פרטים], או לפנות אלינו עד אז אם יש מחלוקת על החישוב.
5. אם החוב לא יוסדר, הוועד יבחן את המשך הטיפול בנושא.

בברכה,
[שמות חברי הוועד וחתימות]
```

נספח לדרישה: טבלה של חודש, סכום שנדרש, סכום ששולם, יתרה.

**דף עובדות לפני פנייה למפקח (לא כתב תביעה):**
- כתובת הבית, מספר הדירות, מספר גוש וחלקה אם ידוע
- פרטי בעל הדירה החייב
- בסיס החלוקה (שטחים, סעיף בתקנון אם יש)
- החלטות האסיפה שעליהן מסתמכים ותאריכיהן
- טבלת החוב לפי חודשים
- כל התזכורות והדרישות שנשלחו, עם תאריכים
- פרוטוקול בחירת הוועד, פנקס ההכנסות שמראה את החוב, והתקנון אם יש
- את כתב התביעה עצמו מנסחים במערכת המקוונת של משרד המשפטים או עם עורך דין

## 7. נזילה מדירה אחרת או מהרכוש המשותף

**מכתב לשכן:**
```
[תאריך]
היי [שם], שלום,
מ-[תאריך] יש אצלנו רטיבות בתקרה של [חדר], מתחת ל[אמבטיה / מטבח] שלכם. מצורפות תמונות מ-[תאריכים].
נבקש לתאם בדיקה של אינסטלטור אצלכם עד [תאריך] כדי לאתר את המקור.
אם המקור בצנרת הפרטית שלכם, נבקש שתתקנו אותו; אם המקור בצנרת משותפת, נפנה יחד לוועד.
תודה, [שם], דירה [מספר], [טלפון]
```

**מכתב לוועד (מקור ברכוש המשותף, למשל הגג):**
```
[תאריך]
לוועד הבית, שלום,
מ-[תאריך] נכנסים מים לדירה [מספר] מ[הגג / הקיר החיצוני / צינור משותף]. מצורפים תמונות ו[ממצא בכתב של בעל מקצוע].
נבקש שהוועד יזמין בדיקה ותיקון עד [תאריך].
[שם], [טלפון]
```

**יומן תיעוד:**
| תאריך | מה ראיתי / מה נעשה | תמונה או מסמך | למי פניתי ומה ענו |
|---|---|---|---|

## 8. השתלטות על רכוש משותף

```
[תאריך]
לכבוד [שם], דירה [מספר]
בנושא: [הגג / החצר / חדר המדרגות / החניה] ברכוש המשותף

1. [תיאור עובדתי: למשל, מ-[תאריך] הגישה לגג נעולה במנעול שהותקן על ידך, ולשאר הדיירים אין מפתח].
2. [החלק הזה] הוא רכוש משותף של כל בעלי הדירות, ולפי מה שידוע לנו הוא לא מוצמד לדירתך.
3. נבקש [להסיר את המנעול / לפנות את החפצים] עד [תאריך].
4. אם יש בידיך מסמך שמראה הצמדה, נשמח לקבל העתק.

בברכה, [שם / ועד הבית]
```

אל תוסיפו קביעה משפטית על הצמדה או על זכויות; אם השכן טוען להצמדה, בדקו בנסח הטאבו או פנו לעורך דין.
