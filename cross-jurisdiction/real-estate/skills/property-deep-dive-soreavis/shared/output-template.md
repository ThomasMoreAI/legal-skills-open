# Universal MD Output Template

Use this canonical structure for any country's report. Country playbooks may add country-specific blocks but must keep this skeleton.

```markdown
# Property Due-Diligence: <full address>

**Date**: <YYYY-MM-DD>
**Country**: <Country name + flag emoji optional>
**Listing**: <URL or "no listing provided">
**Coordinates**: <lat>, <lon>
**Locality**: <commune/city/Stadt> (<admin code>, <postcode>)
**Population**: <pop> (<trend>)
**Sub-region**: <county/dept/Bundesland/region>

---

<!-- One block per requested section, separated by `---` -->

## Price Assessment
<see shared/sections.md#price>

---

## Traffic Profile
<see shared/sections.md#traffic>

---

## Tax Estimate
<see shared/sections.md#tax>

---

## Rental Income Analysis
<see shared/sections.md#rental>

---

## Local Work Options for <Profession>
<see shared/sections.md#work>

---

## Risk Map
<see shared/sections.md#risks>

---

## Mains Drains Verification
<see shared/sections.md#mains>

---

## TL;DR

- 🔴 / 🟠 / 🟡 / 🟢 <most important finding>
- <second>
- <third>

## Sources

- [Source 1 description](url)
- [Source 2 description](url)
- ...

---

*Generated by `/property-deep-dive` on <date>. Verify all numerics with the seller's diagnostics, the local authority, and a notary/solicitor before signing. AI-assisted research; double-check critical figures.*
```

## Single-section output

When the user requests only one section (e.g., `--risks` only), output just that section under its `## H2` header, plus a brief `## TL;DR` and the `## Sources` block. Skip the unused sections.

## Filename convention

`property-<iso2>-<locality-slug>-<sections-or-all>-<YYYY-MM-DD>.md`

Examples:
- `property-fr-adriers-all-2026-04-25.md`
- `property-de-berlin-mitte-tax-risks-2026-04-25.md`
- `property-uk-bath-all-2026-04-25.md`

## Save-path priority

1. `_local/reports/` if exists in current working directory
2. Else `_local/reports/` if `_local/` exists
3. Else `_local/reports/` if `.gitignore` mentions `_local`
4. Else `<cwd>/<filename>`

If `--save=<path>` is passed, use that path verbatim (create parent dirs if needed).

## Terminal output

Same content as the MD, just printed. Add a final line:

> 📄 *Saved to `<path>`* (only when `--save` was used)

## Slug rules

`<locality-slug>`:
- Lowercase
- Latin transliterate (é → e, ß → ss, etc.)
- Spaces → `-`
- Strip diacritics
- Strip punctuation

`<sections-or-all>`:
- Sort the list of selected sections alphabetically
- Join with `-`
- If `--all`, use `all`

## Frontmatter conventions

- Always include the address verbatim (don't normalise)
- Include both ISO2 country code AND full country name
- Coordinates to 4 decimals
- Population trend as percent change with year (e.g., "-6% since 2006")
- "Listing" line: full URL OR explicit "no listing provided"

## Body conventions

- Use `## H2` for the 7 sections
- Use `### H3` for sub-blocks within a section
- Tables for any 3+ row comparison data
- Inline emoji for verdict colours: 🟢 🟡 🟠 🔴
- Currency: always with the local symbol (€, £, $, CHF, etc.)
- Dates: ISO format (YYYY-MM-DD)
- All claims sourced inline OR collected in the final Sources block
