## Règle de couverture

Lire le module de chaque pays présentant un rattachement significatif : siège, établissement, travailleur, consommateur, personne concernée, serveur ou traitement, bien, garantie, exécution, autorité, juridiction ou marché ciblé. Pour une opération multi-pays, produire une colonne par pays et ne pas fusionner les règles nationales.

Les portails officiels n'offrent pas tous une consolidation ou une recherche équivalente. Lorsque le profil indique une couverture officielle incomplète :

1. rechercher le Journal officiel ou le SGG;
2. consulter l'autorité sectorielle;
3. utiliser une base secondaire uniquement comme piste;
4. demander le texte publié ou une validation locale si l'état de vigueur reste incertain.
