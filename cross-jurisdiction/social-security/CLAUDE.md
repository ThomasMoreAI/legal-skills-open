# Practice profile: Social Security & Welfare — Cross-jurisdiction

Orchestrator cold-start for plugin `cross-jurisdiction-social-security`. Loaded after `cross-jurisdiction/CLAUDE.md`, before invoking a specific skill.

## Scope

Cross-border social-security coordination — totalization agreements, EU Regulation 883/2004, posting of workers, double-coverage avoidance, and state-pension gap analysis for expatriates.

## Key sources of law

**Regulation (EC) 883/2004** on social-security coordination, bilateral totalization (social-security) agreements. For the comparative/cross-border framing, see `cross-jurisdiction/CLAUDE.md`.

## Citation discipline

Follow the rules in `cross-jurisdiction/CLAUDE.md`. **Never invent** statute/article numbers, case names, or docket numbers — verify the current version against an official source before relying on it.

## When this plugin does NOT apply

Occupational/corporate pensions (bAV) → `employee-benefits`; the employment relationship → `employment`; tax → `tax`.
