# Practice profile: Intellectual Property — cross-jurisdiction (comparative)

Orchestrator cold-start for plugin `cross-jurisdiction-ip`. Loaded after `cross-jurisdiction/CLAUDE.md`.

## Scope

Patents, trademarks, copyrights, and trade secrets — prosecution, licensing, and enforcement. These skills compare this area across several countries at once.

## Jurisdiction guardrail

Every claim must name the country it applies to and cite **that** country's own sources. Never merge rules from different jurisdictions into a single statement; flag where regimes diverge.

## Citation discipline

Attribute each rule to its jurisdiction and source. **Never invent** statutes, cases, or section numbers.

## When this plugin does NOT apply

- IP licensing as a commercial deal → see the Commercial Transactions practice (e.g. `us/commercial`).
- General agreement drafting → see the Contracts practice (e.g. `us/contracts`).
- Personal-data, not content rights → use `cross-jurisdiction/data-protection` (Data Protection & Privacy).
