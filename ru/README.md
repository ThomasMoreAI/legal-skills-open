# Юрисдикция: Российская Федерация (`ru`)

Навыки, рассчитанные на работу с правом Российской Федерации. Внутри сгруппированы по отраслям права; каждая отрасль — отдельный плагин в подкаталоге.

Язык документов и навыков — русский.

## Текущие плагины

| Плагин | Отрасль права | Что внутри |
|---|---|---|
| [`arbitration/`](arbitration/) | Арбитражный процесс | Расчёты пошлин, анализ судебной практики, документы для арбитражных судов |

## Сквозной контекст для навыков

Файл [`CLAUDE.md`](CLAUDE.md) — холодный старт оркестратора по правовой системе РФ: иерархия источников права, общие правила цитирования, дисциплина работы с редакциями законов. Подгружается до плагин-специфичного `CLAUDE.md` каждого плагина внутри `ru/`.
