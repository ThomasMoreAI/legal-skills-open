# 智能合同生成器

根据合同类型自动生成符合中国法律规范的 .docx 合同文档。

> **免责声明：本工具生成的合同模板仅供参考，不构成法律建议。重要合同请咨询专业律师审核。**

## When to Use

- 用户需要起草各类合同或协议
- 用户说"帮我写一份XX合同"
- 用户需要标准合同模板
- 用户需要在已有合同中添加/修改条款

## When NOT to Use

- 党政机关公文 → 使用 `wps-gongwen`
- 普通Word文档 → 使用 `wps-docx-writer`
- 合同中的数据表格处理 → 使用 `wps-formula`

## 支持的合同类型

| 类型 | 适用场景 | 核心条款 |
|------|---------|---------|
| **劳动合同** | 企业雇佣员工 | 岗位、薪酬、工时、社保、试用期、竞业限制 |
| **劳务合同** | 非劳动关系的服务 | 服务内容、报酬、期限、不构成劳动关系声明 |
| **租赁合同** | 房屋/设备/车辆租赁 | 租金、押金、维修责任、提前解约 |
| **买卖合同** | 商品购销 | 标的物、价格、交付、验收、质保 |
| **技术开发合同** | 软件/系统开发 | 需求范围、交付物、验收标准、知识产权 |
| **保密协议(NDA)** | 商业秘密保护 | 保密范围、期限、违约金、例外情形 |
| **合作协议** | 业务合作 | 合作模式、分工、收益分配、退出机制 |
| **股权转让协议** | 股权交易 | 转让价格、交割条件、陈述保证、过渡期 |
| **借款协议** | 民间借贷 | 借款金额、利率、还款方式、担保 |
| **代理协议** | 代理销售/采购 | 代理范围、佣金、独家/非独家 |
| **竞业限制协议** | 员工离职后限制 | 限制范围、期限、补偿金 |
| **服务协议(SLA)** | IT/咨询服务 | 服务范围、SLA指标、响应时间、付款 |

## 工作流程

### Step 1: 确认合同要素

**必填信息：**
- **合同类型**：从上表选择
- **甲方信息**：名称（个人/公司）
- **乙方信息**：名称（个人/公司）
- **核心商业条款**：金额、期限、标的物等

**可选信息（未提供则使用通用条款）：**
- 争议解决方式（仲裁/诉讼，管辖地）
- 违约金比例
- 保密条款
- 不可抗力条款
- 通知方式
- 合同份数

### Step 2: 生成合同内容

**合同基本结构：**

```text
合同编号：[编号]
                    [合同标题]

甲方（全称）：_______________
统一社会信用代码/身份证号：_______________
法定代表人/负责人：_______________
地址：_______________
联系电话：_______________

乙方（全称）：_______________
（同上字段）

鉴于：
  [合同背景和缔约目的]

双方经友好协商，根据《中华人民共和国民法典》及相关法律法规，
就[事项]达成如下协议：

第一条  [标的/服务内容]
第二条  [价格/报酬]
第三条  [付款方式]
第四条  [交付/履行]
第五条  [验收标准]
第六条  [双方权利义务]
第七条  [违约责任]
第八条  [保密条款]
第九条  [不可抗力]
第十条  [争议解决]
第十一条  [其他约定]
第十二条  [合同生效]

甲方（盖章）：              乙方（盖章）：
法定代表人/授权代表：        法定代表人/授权代表：
日期：    年  月  日         日期：    年  月  日
```

### Step 3: 生成 .docx 文件

**先确保依赖：**
```bash
pip install python-docx 2>/dev/null || pip3 install python-docx 2>/dev/null
```

**排版规范：**
```text
纸张：A4
页边距：上下左右各 2.54cm（Word默认）
标题：二号黑体，居中
合同编号：小四号宋体，右对齐
正文：小四号宋体，行距1.5倍
条款标题："第X条"加粗
首行缩进：2字符
签署栏：左右分列，甲方左侧，乙方右侧
页脚：页码居中
```

**金额大小写规范：**
```text
合同中出现金额时必须同时标注大小写：
人民币（大写）：壹拾万元整
人民币（小写）：¥100,000.00

大写数字对照：
零、壹、贰、叁、肆、伍、陆、柒、捌、玖
拾、佰、仟、万、亿
元、角、分、整
```

### Step 4: 交付

1. 生成 .docx 文件
2. 提醒用户：
   - 核对甲乙方信息是否准确
   - 检查金额和日期
   - 重要合同请律师审核
   - 签署前双方确认所有条款

## 通用条款库

### 违约责任（通用）

```text
任何一方违反本合同约定的，应向守约方支付合同总金额[  ]%的违约金。
违约金不足以弥补守约方实际损失的，违约方应当赔偿差额部分。
```

### 争议解决

```text
【仲裁版】
因本合同引起的或与本合同有关的任何争议，均提交[城市]仲裁委员会，
按照申请仲裁时该会现行有效的仲裁规则进行仲裁。仲裁裁决是终局的，
对双方均有约束力。

【诉讼版】
因本合同引起的或与本合同有关的任何争议，双方应友好协商解决；
协商不成的，任何一方可向甲方所在地有管辖权的人民法院提起诉讼。
```

### 保密条款

```text
双方对在履行本合同过程中知悉的对方商业秘密和技术秘密负有保密义务，
未经对方书面同意，不得向任何第三方披露。保密期限自本合同签订之日起
[  ]年，不因本合同的解除或终止而失效。
```

### 不可抗力

```text
因地震、台风、洪水、疫情、战争、政府行为等不可抗力事件导致一方
不能履行或不能完全履行本合同的，该方不承担违约责任，但应在不可抗力
事件发生后[  ]日内书面通知对方，并在[  ]日内提供相关证明文件。
```

### 通知条款

```text
本合同项下的所有通知应以书面形式发出，通过以下方式送达：
（1）专人递送：送达之日视为送达；
（2）挂号信：自发出之日起第[  ]个工作日视为送达；
（3）电子邮件：发送成功之日视为送达。
```

## 示例

```bash
# 生成劳动合同
/wps-contract 劳动合同 甲方为杭州XX科技有限公司，月薪15000，试用期3个月

# 生成保密协议
/wps-contract NDA 甲方XX公司和乙方XX公司之间的双向保密协议，保密期限3年

# 生成租赁合同
/wps-contract 租赁合同 出租方张三，承租方李四，月租金5000元，押一付三
```
