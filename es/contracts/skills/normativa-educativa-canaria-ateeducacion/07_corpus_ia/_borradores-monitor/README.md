# Borradores del monitor de normativa

Esta carpeta contiene **material de partida no validado**: textos convertidos
automáticamente a Markdown por DocDigester2MD a partir de los PDFs que el
[monitor de vigilancia](../../11_calidad/monitor/README.md) detecta en el portal
oficial.

> ⚠️ Estas copias **no sustituyen la fuente oficial** ni confirman vigencia.
> No son fichas del corpus (`NOR`/`FTE`/`CHUNK`): son insumo para la
> catalogación supervisada (AGENTS.md §7–§8 y §10 bis).

Cada borrador llega dentro de un Pull Request etiquetado `monitor-normativa`,
con una cabecera de aviso (R16) que indica fecha de exportación y origen. Tras
catalogar la normativa correspondiente, mueve o elimina el borrador según
proceda; no se publica en GitHub Pages (queda fuera de los disparadores de
`pages.yml`).
