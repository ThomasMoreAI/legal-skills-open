## 2. Nachweise pro Schadenart

### Universell benoetigte Nachweise

| Nachweis | Wofuer | Wie beschaffen |
|---------|--------|---------------|
| Schadenmeldung (Formular) | Alle Versicherungen | Online oder Telefon, dann schriftlich bestaetigen |
| Fotos | Alle Sachschaeden | Uebersicht + Detail, Datum/Uhrzeit im Bild |
| Polizeirapport | Diebstahl, Einbruch, Verkehrsunfall | Automatisch nach Meldung, Rapportnummer notieren |
| Arztzeugnis (AUF) | Personenschaden, Arbeitsunfaehigkeit | Beim Arzt, sofort nach Vorfall |
| Kostenvoranschlag | Sachschaeden | Fachbetrieb, mind. 1-2 Offerten |
| Kaufbelege | Hausrat, Gegenstaende | Eigene Unterlagen, ev. Bankauszug |
| Zeugenaussagen | Bei strittigen Faellen | Schriftliche Bestaetigung von Zeugen |

### Spezifische Nachweise nach Kategorie

| Kategorie | Zusaetzliche Nachweise |
|-----------|----------------------|
| **Arbeitsunfall (UVG)** | UVG-Unfallmeldung (Arbeitgeber), Lohnausweis |
| **Verkehrsunfall** | Europaeisches Unfallprotokoll, Skizze, Gegnerische Versicherung |
| **Einbruch** | Polizeirapport (Pflicht!), Liste gestohlener Gegenstaende |
| **Wasserschaden** | Fotos vor Trocknung, Handwerker-Rapport, ev. Leckortung |
| **Feuer** | Feuerwehr-Rapport, Fotos, Liste beschaedigter Gegenstaende |
| **Krankheit (KTG)** | AUF-Zeugnisse (lueckenlos), Verlaufsberichte bei laengerer Dauer |
| **Invaliditaet (IV)** | Aerztliche Berichte (alle Behandler), Arbeitgeber-Bericht, Funktionsbericht |
| **Todesfall** | Todesbescheinigung, Zivilstandsnachweis, Erbschein, PK-Ausweis |
| **Reise-Annullierung** | Buchungsbestaetigung, Stornierungsbeleg, Arztzeugnis (bei Krankheit) |
| **Gepaeckverlust** | PIR-Formular (Flughafen), Boardingpass, Inhaltsverzeichnis |
| **Rechtsstreit** | Komplette Korrespondenz chronologisch, Vertraege, Verfuegungen |

## 3. Leistungsprozess pro Versicherungstyp

### UVG (Unfallversicherung)

```
Unfall → Arbeitgeber melden → UVG-Meldung an Versicherer (Suva, Helsana, etc.)
→ Taggeld 80% ab 3. Tag → Heilungskosten 100%
→ Falls bleibend: Integritaetsentschaedigung + ev. Invalidenrente
→ Dauer: Taggeld bis Abschluss Heilbehandlung (kein Maximum)
```

### KTG (Krankentaggeld)

```
Krankheit → Arztzeugnis → Arbeitgeber meldet KTG-Versicherer
→ Wartefrist (je nach Police) → Taggeld 80% bis 720 Tage
→ Falls laenger: IV-Anmeldung parallel
→ Ende KTG ≠ automatisch IV-Rente (Luecke moeglich!)
```

### IV (Invalidenversicherung)

```
Arbeitsunfaehigkeit >6 Mt → Anmeldung IV-Stelle
→ Abklaerung (medizinisch + beruflich): 12-24 Monate
→ Eingliederungsmassnahmen (Umschulung, Arbeitsversuch)
→ IV-Verfuegung: IV-Grad → Rentenanspruch
→ Falls IV-Grad ≥40%: Rente + BVG-Invalidenrente
```

### Haftpflicht (VVG)

```
Schadenfall → Meldung an eigene HP-Versicherung
→ Versicherung prueft Haftpflicht (ja/nein)
→ Versicherung verhandelt mit Geschaedigtem
→ Zahlung oder Abwehr unberechtigter Forderungen
→ Dauer: 1-6 Monate (einfach), bis Jahre (komplex/Gericht)
```

### Hausrat

```
Schadenfall → Dokumentation → Meldung an Versicherung
→ Ev. Inspektion durch Schadenexperte
→ Schaetzung/Nachweis der beschaedigten Gegenstaende
→ Leistung: Zeitwert oder Neuwert (je nach Police)
→ Dauer: 2-8 Wochen (einfach), bis Monate (komplex)
```

### Auto (Kasko)

```
Schadenfall → Dokumentation → Meldung an Versicherung
→ Werkstatt-Kostenvoranschlag
→ Ev. Besichtigung durch Versicherungs-Experten
→ Freigabe Reparatur oder Totalschaden-Abrechnung
→ Leistung minus Selbstbehalt
→ Bonus-Malus-Stufenaenderung bei Schadenmeldung
→ Dauer: 1-4 Wochen
```

## 4. Schadenminderungspflicht (VVG Art. 61)

### Was bedeutet Schadenminderungspflicht?

Der Versicherte MUSS alles Zumutbare tun, um den Schaden zu begrenzen. Wer dies unterlaesst, riskiert eine Leistungskuerzung.

### Beispiele

| Situation | Pflicht | Versaeumnis-Konsequenz |
|-----------|--------|----------------------|
| Wasserschaden | Haupthahn zudrehen, Wasser aufwischen | Leistungskuerzung fuer Folgeschaeden |
| Einbruch | Provisorisch sichern (Schloss, Fenster) | Folgeschaeden nicht gedeckt |
| Autounfall | Fahrzeug sichern, Bergung veranlassen | Folgeschaeden (Standschaden) nicht gedeckt |
| Feuer | Feuerwehr rufen, Loeschversuch wenn sicher | Leistungskuerzung moeglich |
| Diebstahl | Polizei melden, gestohlene Karten sperren | Leistungsverweigerung moeglich |
| Personenschaden | Arzt aufsuchen, Anweisungen befolgen | Leistungskuerzung bei Nichtbehandlung |

### Was NICHT tun

- Schaden aufraemen vor Dokumentation (Fotos zuerst!)
- Reparatur ohne Freigabe der Versicherung (ausser Notmassnahme)
- Schaeden vergroessern durch Untaetigkeit
- Beschaedigte Gegenstaende entsorgen vor Inspektion

## 5. Ombudsman & Beschwerdeweg

### Ombudsman der Privatversicherung und der Suva

| Aspekt | Details |
|--------|---------|
| Zustaendigkeit | Streitigkeiten mit privaten Versicherern (VVG) und Suva |
| Kosten | Kostenlos fuer Versicherte |
| Unabhaengigkeit | Neutral, von Versicherungsbranche finanziert |
| Kontakt | ombudsman-assurance.ch |
| Verfahren | Schriftliche Eingabe → Vermittlung → Empfehlung |
| Dauer | 1-3 Monate |
| Bindung | Empfehlung ist nicht bindend, aber meistens befolgt |

### Eskalationsstufen

```
Stufe 1: Direktkontakt mit Versicherung
         → Schriftliche Beanstandung mit Fristsetzung (14 Tage)

Stufe 2: Eskalation intern
         → Beschwerdemanagement / Kundenombudsman des Versicherers

Stufe 3: Externer Ombudsman
         → ombudsman-assurance.ch (kostenlos, neutral)

Stufe 4: Aufsichtsbeschwerde
         → FINMA (bei systematischem Fehlverhalten)

Stufe 5: Gericht
         → Friedensrichter (bis CHF 2'000)
         → Schlichtungsbehoerde (arbeits-/mietrechtlich)
         → Bezirksgericht (Zivilklage)
         → Versicherungsgericht (Sozialversicherungen)
```

### FINMA-Beschwerde

| Aspekt | Details |
|--------|---------|
| Wann | Bei systematischem Fehlverhalten des Versicherers |
| Wann NICHT | Bei Einzelstreitigkeiten (dafuer Ombudsman oder Gericht) |
| Form | Schriftlich an FINMA |
| Ergebnis | FINMA kann keine Einzelfaelle loesen, aber Aufsichtsmassnahmen ergreifen |

## 6. Europaeisches Unfallprotokoll

### Aufbau und Ausfuellhilfe

Das Europaeische Unfallprotokoll (Constat amiable) ist in der Schweiz nicht obligatorisch, aber von allen Versicherern anerkannt und empfohlen.

| Abschnitt | Inhalt |
|-----------|--------|
| 1-5 | Datum, Ort, Verletzte, Sachschaeden, Zeugen |
| 6-8 | Versicherungsnehmer A + B (Name, Adresse, Versicherung, Police-Nr.) |
| 9 | Fahrzeuge (Marke, Kennzeichen) |
| 10 | Schaeden an den Fahrzeugen |
| 11 | Skizze des Unfalls |
| 12 | Hergang mit Ankreuzfeldern |
| 13 | Unterschriften beider Parteien |

### Wichtige Regeln

- **IMMER im Auto mitfuehren** (Handschuhfach)
- **Vor Ort ausfuellen** (nicht erst zu Hause)
- **Beide Parteien unterschreiben**
- **Nicht nachtraeglich aendern** (das Original zaehlt)
- **Jede Partei erhaelt eine Kopie** (Durchschlag)
- **Auch bei klarer Schuld ausfuellen** (vereinfacht Regulierung)

## 7. Bonus-Malus-System (Auto)

### Funktionsweise

| Schadenfall | Auswirkung |
|------------|-----------|
| Schadenfreies Jahr | 1 Stufe besser (tiefere Praemie) |
| 1 Haftpflicht-Schaden | 3-4 Stufen schlechter (hoehere Praemie) |
| 1 Kasko-Schaden | 2-3 Stufen schlechter (nur bei einigen Anbietern) |
| Parkschaden (unbekannt) | Kasko-Schaden (Stufenverschlechterung) |
| Glasschaden (Teilkasko) | Meist keine Stufenverschlechterung |
| Wildtier/Naturereignis | Teilkasko: Meist keine Verschlechterung |

### Selbst-zahlen-oder-melden-Entscheidung

```
Entscheidungslogik:
  Schadenshoehe < Selbstbehalt
    → NICHT melden (keine Leistung, aber Bonus-Verlust)

  Schadenshoehe = Selbstbehalt bis +CHF 500
    → Abwaegen: Leistung (CHF 0-500) vs. Bonus-Verlust (ev. CHF 500-1'500 ueber Jahre)
    → Oft besser NICHT melden

  Schadenshoehe >> Selbstbehalt
    → MELDEN (Leistung ueberwiegt Bonus-Verlust)

  Faustformel:
    Wenn Leistung (Schaden - SB) < 2x jaehrliche Bonus-Verschlechterung
    → Nicht melden, selbst zahlen
```

## 8. Zeitwert vs. Neuwert (Hausrat/Sachversicherung)

### Entschaedigungsprinzipien

| Prinzip | Beschreibung | Typisch fuer |
|---------|-------------|-------------|
| **Neuwert** | Kosten fuer gleichwertigen Neukauf | Modernere Policen, Standardoption |
| **Zeitwert** | Neuwert minus Altersentwertung | Aeltere Policen, oder bei Gegenstaenden >X Jahre |
| **Wiederbeschaffungswert** | Preis am Markt fuer gleichwertigen Gebrauchten | Occasion-Fahrzeuge, Antiquitaeten |

### Zeitwert-Berechnung (Richtwerte)

| Gegenstand | Lebensdauer | Zeitwert nach 5 Jahren |
|-----------|-----------|----------------------|
| Elektronik (TV, Laptop) | 5-8 Jahre | 30-50% des Neuwerts |
| Moebel | 15-20 Jahre | 70-80% |
| Kleidung | 3-5 Jahre | 20-40% |
| Haushaltgeraete | 10-15 Jahre | 60-70% |
| Fahrrad | 8-10 Jahre | 50-60% |
| Schmuck | Unbegrenzt | 100% (Sachwert) |
