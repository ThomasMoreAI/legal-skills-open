# Open-Source License

Use this skill when releasing or using open-source code, datasets, or models.

## Workflow

1. Inventory project licenses and dependency licenses.
2. Classify obligations: attribution, notice, source disclosure, patent grant,
   commercial restrictions, model/data restrictions, and redistribution.
3. Flag ambiguous or high-risk combinations for counsel.
4. Draft README/license notices based on verified metadata.

## Output

Return `License inventory`, `Obligations`, `Compatibility questions`,
`Attribution draft`, and `Counsel checklist`.
