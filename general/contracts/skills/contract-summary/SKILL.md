# Contract Summary

Use this skill to understand a contract before signing, negotiating, or sending
it to counsel.

## Workflow

1. Identify document type, parties, dates, term, scope, and payment.
2. Extract obligations, deadlines, termination, renewal, IP, confidentiality,
   liability, indemnity, dispute resolution, and governing law.
3. Translate clauses into operational consequences.
4. Build lawyer-ready questions and negotiation points.

## Output

Return `Plain-English summary`, `Obligation table`, `Risk clauses`, `Questions
for counsel`, and `Negotiation notes`.
