# Negotiation Email

Use this skill when asking for contract changes.

## Workflow

1. Identify relationship, leverage, must-have changes, nice-to-have changes, and
   fallback.
2. Convert legal concerns into business-friendly language.
3. Keep tone collaborative, short, and specific.
4. Include redline instructions only if requested.

## Output

Return `Email draft`, `Ask table`, `Fallback wording`, `Tone notes`, and
`Counsel-review flags`.
