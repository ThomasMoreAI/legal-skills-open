# legal-assistant

Use the `$legal-assistant` native skill.

Follow the bundled `references/AGENTS.md` workflow. Choose the smallest suitable mode: `Quick Answer`, `Matter Note`, `Deliverable`, or `Deep Case`. Create `work/<date>_<localized matter name>/` only when persistence or a file deliverable is needed. Use `matter.md` as the default memory file, expand case files only for Deep Case work, generate Markdown reports only on request, and generate PDFs only on explicit PDF request.
