# Secondary Sources - Bluebook Rules 15-18

Guidance for citing books, articles, treatises, and other secondary sources per the Bluebook **22nd
Edition**. Page cites below are 22e pages, taken from the rule headings of the official Bluebook
Online 22nd edition.

## Books and Treatises (Rule 15)

### Basic Form

```
[Author(s)], [Title] [Pinpoint] ([Edition] [Year]).
```

**Example:**
```
Deborah L. Rhode, Justice and Gender 56 (1989).
```
(The Bluebook's own example, from rule 15.4(a)(i).)

### Author Names (Rule 15.1) (22e pp. 154-56)

Give the author's full name **as it appears on the publication**, including a designation such as
"Jr." or "III" (comma before it only if the author uses one). **Do not** include "Dr.," "Prof.,"
"Judge," or "Justice" even if it appears on the title page. Author names in book citations are set
in **small capitals** ("Use small capitals").

**Single author:**
```
Michael Vorenberg, Final Freedom: The Civil War, the Abolition of Slavery, and the
Thirteenth Amendment 143-44 (2001).
```

**Two or three authors (15.1(a)):** list all names in title-page order. Two authors are joined by an
ampersand; for three, use commas except before the final name, which takes an ampersand with **no**
comma.
```
Chris Hedges & Joe Sacco, Days of Destruction, Days of Revolt 109 (2012).
```

If the title page establishes an alternative relationship ("with," "as told to"), use that phrase to
separate the names:
```
Earvin "Magic" Johnson with William Novak, My Life 39 (1993).
```

**More than three authors (15.1(b)):** "et al." is available only above three. Use the first author's
name followed by "et al." when saving space is desired and in short forms; list all names when
particularly relevant.
```
A. Leo Levin et al., Dispute Resolution Devices in a Democratic Society 77 (1985).
Richard H. Fallon, Jr., John F. Manning, Daniel J. Meltzer & David L. Shapiro, Hart and
Wechsler's the Federal Courts and the Federal System 330 (6th ed. 2009).
```

**Institutional author (15.1(c)):** begin with the institution's complete name, abbreviated per
15.1(e). When an individual is credited on behalf of an institution, give the individual's name and
then the institution's; include subdivisions only if particularly relevant.
```
City of New Haven, Recycle Now New Haven (1991).
S. Elizabeth Gibson, Fed. Jud. Ctr., Case Studies of Mass Tort Limited Fund Class Action
Settlements & Bankruptcy Reorganizations 39-45 (2000).
```
When no individual is credited, use the smallest subdivision that prepared the work, then the
overall body:
```
Statistical Analysis Ctr., State Crime Comm'n, Crime in Georgia 41 (1980).
```

**Pen names (15.1(d)).** Where an author of an article, newspaper publication,
correspondence, pamphlet, or book uses an obvious alias, put the alias in quotation marks; if the
real author is verifiably known, give that name in parentheses after the alias. This does not alter
rule 15.8(c)(i) (The Federalist).
```
"William Penn" (Jeremiah Everts), Essays on the Present Crisis in the Condition of the
American Indians ... (Boston, Perkins & Marvin, 1829).
```
If the work was published under an alias but the real author is verified, common knowledge, and
almost universally credited in later editions, **drop the alias**:
```
Thomas Paine, Common Sense (Philadelphia, R. Bell 1776).
```
When an author is known primarily by their pen name, you may omit the legal name:
```
Mark Twain, The Adventures of Huckleberry Finn (Union Square & Co. 2024) (1884).
```

**Abbreviations (15.1(e)):** abbreviate an institutional author's name only if the result is
completely unambiguous, using tables T6 and T10. Omit "Inc.," "Ltd.," and similar terms if the name
also contains "Ass'n," "Bros.," "Co.," or "Corp."

**Tribal affiliation (15.1(f)):** if an author indicates a tribal affiliation, it may be given in
parentheses after the first mention of the name, once. Use the specific Tribal Nation(s) or
Indigenous group(s), not broad terms like "Native American"; follow the author's preferred
terminology.
```
Ned Blackhawk (Western Shoshone), The Rediscovery of America 15 (2023).
```

### Titles (Rule 15.3) (22e p. 157)

Cite the full main title as it appears on the title page, capitalized per rule 8 (22e pp. 96-99) (or
rule 20.2.2(b) if not in English). Rule 8(a): "Capitalize words in a heading or title, including the
initial word and any word that immediately follows a colon. Do not capitalize articles,
conjunctions, or prepositions when they are four or fewer letters, unless they begin the heading or
title, or immediately follow a colon." **Give a subtitle only if it is particularly relevant.** Do not abbreviate words
or omit articles. Use small capitals.

Rule 15.3's own example (a work with editors rather than an author):
```
CAPITAL FLOWS IN THE APEC REGION (Mohsin S. Khan & Carmen M. Reinhart eds., 1995).
```

If the title ends with a numeral, or distinguishing title from page number would otherwise confuse,
set the page off with a comma and "at" (rule 3.2(a)):
```
J.A.S. Grenville, THE MAJOR INTERNATIONAL TREATIES, 1914-1973, at 114-15 (1974).
```

### Editors and Translators (Rule 15.2) (22e pp. 156-57)

Give the full name of an editor and/or translator per 15.1, followed by "ed.," or "trans.," **in
that order if both apply**, inside the edition/publisher/date parenthetical (rule 15.4). A comma
separates that designation from the other publication information.

```
Michel Foucault, Discipline and Punish 30-31 (Alan Sheridan trans., Vintage Books 2d ed. 1995) (1975).
Karl Marx & Frederich Engels, The Communist Manifesto (Joseph Katz ed., Samuel Moore trans.,
Washington Square Press 1964) (1848).
```

**Institutional editors (15.2(b)):** follow 15.1(c), abbreviating per 15.1(e).
**Different editors by volume (15.2(c)):** list only the editors of the volume cited.
**No named parties (15.2(d)):** a work with no author, editor, or translator may be designated by
the publisher of the edition (rule 15.4).

### Edition, Publisher, and Date (Rule 15.4) (22e pp. 157-59)

Always cite the **latest** edition that supports the point, unless an earlier edition is
particularly relevant or authoritative.

**Single edition (15.4(a)(i)):** give the year of publication in parentheses; cite by the date of
the edition rather than of a particular printing, unless the printing differs in a relevant respect
(then "(6th prtg. 1980)"). If the title incorporates the date, do not omit the publication date even
when identical.
```
Deborah L. Rhode, Justice and Gender 56 (1989).
```

**Multiple editions by the same publisher (15.4(a)(ii)):** give the edition and its year, following
the publisher's own terminology (see table T14).
```
Fleming James, Jr. et al., Civil Procedure § 2.3 (4th ed. 1992).
```

**Publisher.** 15.4 names the publisher as a required element in exactly two situations, and its
15.4(a)(i)-(ii) examples (`Deborah L. Rhode, Justice and Gender 56 (1989).`) carry none — so the
publisher is in practice omitted for the original publisher's edition, though no sentence of 15.4
says so in terms. The publisher is **required** when the work was published by someone other than
the original publisher (15.4(a)(iii)
— give editor/translator, publisher, edition if not the first, and date, then a second parenthetical
with the original edition's date unless the work is regularly updated), and for pre-1900 works
(15.4(d)).
```
Charles Dickens, Bleak House 49-55 (Norman Page ed., Penguin Books 1971) (1853).
```

**Pre-1900 works (15.4(d)):** cite to a scholarly modern edition per 15.4(a). If none exists, cite
the first edition and give the place of publication (states/countries abbreviated per T10) and the
publisher, separated by a comma. Use "n.p." or "n.d." where place or date is unavailable.
```
1 James Fitzjames Stephen, A History of the Criminal Law of England 156-57 (London, MacMillan & Co. 1883).
```

**Photoduplicated reprints (15.4(c)):** cite to the original, noting the reprint and its date, then
the original publication date in separate parentheses.
```
Paul W. Gates, History of Public Land Law Development 1 (photo. reprt. 1979) (1968).
```

### Supplements and Pocket Parts (Rule 15.4(e))

Cite pocket parts and bound supplements per rule 3.1(c):
```
5 Samuel Williston & Richard A. Lord, A Treatise on the Law of Contracts § 11:8 (4th ed. 1993 & Supp. 1999).
```

### Special Pagination (Rule 15.8(b))

Where a well-known work has standardized pagination across editions (usually shown in the margin),
the date and edition **may be omitted** and the citation made to the standardized page — unless the
material cited was inserted by the editor of the edition cited.
```
2 William Blackstone, Commentaries *152, *155-56.
Aristotle, Nichomachean Ethics 1094a1 (C.D.C. Reeve trans.).
William Shakespeare, Henry V act 4, sc. 3, I. 65.
```

### Shorter Works in Collection (Rule 15.5) (22e pp. 159-60)

**Works by various authors (15.5.1(a)):** author's full name in **ordinary roman**, the shorter
work's title in *italics*, the word *in* in italics, the volume number if any, and the name of the
volume as a whole in small capitals. Always give the page on which the shorter work begins as well
as any pinpoint pages.
```
Kay Deaux & Brenda Major, A Social-Psychological Model of Gender, in Theoretical Perspectives
on Sexual Difference 89, 89 (Deborah L. Rhode ed., 1990).
```

**Works all by the same author (15.5.1(b)):** same form, but the author's name is in small capitals
and the volume number, if any, precedes the author's name.

**Collected documents previously published (15.5.2(a)):** use the "reprinted in" form (rule
1.6(a)(ii)) — full citation to the original, then "reprinted in" and the volume containing the
reprint. Documents originally unpublished are cited per rule 23.

### Prefaces, Forewords, Introductions, and Epilogues (Rule 15.6) (22e p. 160)

By someone other than the author:
```
L. Maria Child, Introduction to Harriet A. Jacobs, Incidents in the Life of a Slave Girl 3, 3-4
(L. Maria Child & Jean F. Yellin eds., Harvard Univ. Press 1987) (1861).
```
Cite similar material **by** the author of the work without special designation:
```
John Hart Ely, Democracy and Distrust, at vii (1980).
```

### Serial Number (Rule 15.7)

**Series issued by the author (15.7(a)):** the corpus page's two examples for this subpart place the
serial number after the institutional author and **before** the title (the subpart's own heading line
is truncated in the corpus — see the marker below):
```
Bureau of Intel. & Rsch., U.S. Dep't of State, Pub. No. 8732, World Strength of the Communist
Party Organizations 65 (1973).
Women's Bureau, U.S. Dep't of Lab., Leaflet No. 55, A Working Woman's Guide to Her Job Rights 4 (1978).
```
Rule 14.2(d) ("Other publications") points back here: cite such a publication "as a work by an
institutional author (rule 15.1(c)), including a serial number, if any (rule 15.7), unless issued as
a congressional document (rule 13.4)."

**Series issued by someone other than the author (15.7(b)):** indicate the series and number
parenthetically, abbreviating institutional entities per 15.1(e):
```
Anne C. Vladeck, Counseling a Plaintiff During Litigation, in Employment Litigation 1990, at 77,
80-82 (PLI Litig. & Admin. Prac., Course Handbook Ser. No. 386, 1990).
```

## Periodical Materials (Rule 16)

### Law Review Articles (Rule 16.4, consecutively paginated) (22e pp. 167-68)

**Basic form:**
```
[Author], [Title], [Vol.] [Journal] [First Page], [Pinpoint] ([Year]).
```

**Example:**
```
David Rudovsky, Police Abuse: Can the Violence Be Contained?, 27 Harv. C.R.-C.L. L. Rev. 465, 500 (1992).
```

If the periodical has **no volume number** but is consecutively paginated through each volume, use
the year as the volume number and omit the year parenthetical:
```
Thomas R. McCoy & Barry Friedman, Conditional Spending: Federalism's Trojan Horse, 1988 Sup. Ct. Rev. 85, 100.
```

Journals with separate-but-consecutive pagination keep the special numbering (`16 Pepp. L. Rev. S5,
S14 n.19 (1989)`); special annual issues are designated parenthetically (`6 J.L. Econ. & Org.
(Special Issue) 1 (1990)`).

### Nonconsecutively Paginated Journals and Magazines (Rule 16.5) (22e p. 168)

Author, title, periodical name, **date of issue as it appears on the cover**, the word "at" (rule
3.2(a)), first page, then any pinpoint pages. If no author is listed, begin with the title.
```
Barbara Ward, Progress for a Small Planet, Harv. Bus. Rev., Sep.-Oct. 1979, at 89, 90.
```
If no date of issue is available, give the issue number in its place, put the volume number before
the periodical name per 16.4, and include the year and month of copyright if available:
```
Charles E. Mueller, ..., 34 Antitrust L. & Econ. Rev., no. 1, 2008, at 1, 7.
```

### Typeface for Articles (Rules 16.1, 16.2, 16.3) (22e pp. 165-67)

| Element | Law Review Format |
|---------|-------------------|
| Author name | Roman (16.2 — follow 15.1 "but print in ordinary roman type") |
| Article title | Italics (16.3) |
| Periodical name — journal, magazine **or newspaper** | SMALL CAPS (16.1) |

Rule 16.1: "The name of the periodical should appear in small capitals **whether it is a journal,
magazine, or newspaper**."

Rule 2.1(c)'s own periodical typeface examples:
```
Katharine K. Baker, *Once a Rapist? Motivational Evidence and Relevancy in Rape Law*, 110 HARV. L. REV. 563 (1997).
Cass R. Sunstein, *Lochner's Legacy*, 87 COLUM. L. REV. 873 (1987).
```

When an article title contains material that would be italicized in main text under rule 2.2(a)
(22e pp. 74-76) — 2.2(a) italicizes case names (including "v." and procedural phrases such as "In re"
and "ex rel."), titles of publications, speeches, or articles, and words emphasized for style — that
material appears in **ordinary roman**:
```
Seth F. Kreimer, Does Pro-Choice Mean Pro-Kevorkian? An Essay on Roe, Casey, and the Right to
Die, 44 Am. U. L. Rev. 803, 812 (1995).
```

### Periodical Abbreviations (Tables T6, T10, T13)

Periodical names are abbreviated using **three** tables together. T13's own preamble states the
order of resort: "To abbreviate English language periodical titles, use tables T13, T6, and T10.
Common institutional names (e.g., law schools, professional organizations, and geographic units
commonly found in institutional names) are listed in table T13. If an institutional name is not
listed in table T13, individual words should be abbreviated using tables T6 and T10. If a word in an
institutional name is not listed in these tables, use the full word in the abbreviated periodical
title."

- **T13** — Institutional Names in Periodical Titles (22e pp. 346-48). Look here **first** for the
  institution.
- **T6** — Case Names and Institutional Authors in Citations (22e pp. 333-36). Carries the ordinary
  periodical-title words themselves: "Abbreviate case names, institutional author names, and
  periodical titles in citations by abbreviating any word listed below."
- **T10** — Geographical Terms (22e p. 340; T10.1 U.S. states, cities and territories at pp. 340-42).

Both T6 and T13 carry the same periodical-title conventions: abbreviate "University" as "U."; omit
"a," "at," "in," "of," and "the" (but retain "on"); and if only one word remains after those
omissions, do **not** abbreviate it.

| Full Name | Abbreviation | Table basis |
|-----------|--------------|-------------|
| Harvard Law Review | Harv. L. Rev. | T13 `Harvard → Harv.`; T6 `Law[s] → L.`, `Review, Revista → Rev.` |
| Yale Law Journal | Yale L.J. | "Yale" is not in T13, so it is not abbreviated; T6 `Journal[s] → J.` |
| Stanford Law Review | Stan. L. Rev. | T13 `Stanford → Stan.` + T6 |
| Columbia Law Review | Colum. L. Rev. | T13 `Columbia → Colum.` + T6 |
| University of Pennsylvania Law Review | U. Pa. L. Rev. | T6/T13 "University" → "U." and omit "of"; T10.1 `Pennsylvania → Pa.` |

For a **medical** periodical whose title contains a word not in T6, use the National Library of
Medicine abbreviation for that word if one is available (T6 preamble) — and only for words that have
no standard Bluebook abbreviation.

### Student-Written Pieces (Rule 16.7.1) (within 16.7 Special Citation Forms, 22e pp. 170-74)

**Signed (16.7.1(a)):** cite as any other signed article, with the author's full name in ordinary
roman, **except that the designation appears before the title**. A work is "signed" if a student is
credited anywhere in the issue — first page, end of the piece, or table of contents. **A work signed
only with initials is treated as unsigned.**
```
Ellen London, Comment, A Critique of the Strict Liability Standard ..., 152 U. Pa. L. Rev. 1957, 1959-63 (2004).
B. George Ballman, Jr., Note, Amended Rule 6.1: Another Move Towards Mandatory Pro Bono? Is That What We
Want?, 7 Geo. J. Legal Ethics 1139, 1162 n.155 (1994).
```

Signed, shorter student commentary under a designation such as "Recent Case," "Recent Statute,"
"Recent Decision," "Case Note," "Recent Development," or "Abstract," carrying no title or only a
digest-like heading, is cited by author then designation, **both in ordinary roman**, with any case
or statute citation in the title formatted per 16.3:
```
Sally Anne Moore, Recent Case, H.L. v. Matheson, 101 S. Ct. 1164 (1981), 50 U. Cin. L. Rev. 867, 868 (1981).
```

**Unsigned (16.7.1(b)):** begin with the periodical's designation ("Note," "Comment," "Case
Comment," "Project," "Recent Case," "Case Note") in ordinary roman, followed by the title, if any,
in italics. Where there is no separable designation, italicize the entire title.
```
Note, A Bad Man Is Hard to Find, 127 Harv. L. Rev. 2521 (2014).
Developments in the Law—The Law of Cyberspace, 112 Harv. L. Rev. 1577, 1624 n.95 (1999).
```

**Student-written book reviews (16.7.1(c)):** use the designation **"Book Note" regardless of the
journal's own designation**, followed by the title if any, plus a parenthetical identifying the work
reviewed if relevant.
```
William Dubinsky, Book Note, 90 Mich. L. Rev. 1512 (1992) (reviewing Daniel A. Farber & Philip P.
Frickey, Law and Public Choice (1991)).
```

### Non-Student Book Reviews (Rule 16.7.2)

Reviewer's full name per 16.2, title of the review in italics, and a second parenthetical after the
date identifying the book reviewed if relevant — or simply "(book review)" if identification is
unnecessary. An untitled non-student review is cited by the designation "Book Review."
```
Bruce Ackerman, Robert Bork's Grand Inquisition, 99 Yale L.J. 1419, 1422-25 (1990) (book review).
Howard C. Westwood, Book Review, 45 U. Chi. L. Rev. 255 (1977).
```

### Symposia, Colloquia, and Surveys (Rule 16.7.3)

Citing the **unit**: give no author; put "Symposium," "Colloquium," or "Colloquy" in roman before the
title unless the title makes it clear; cite the first page of the first piece.
```
Symposium, Changing Images of the State, 107 Harv. L. Rev. 1179 (1994).
```
An **individual article** within a symposium is cited exactly like any other article — no symposium
parenthetical:
```
Eric A. Posner, Law, Economics, and Inefficient Norms, 144 U. Pa. L. Rev. 1697 (1996).
```
For an article in a jurisdictional survey, the article's title incorporates the survey title:
```
Alain A. Levasseur, Sales, The Work of the Louisiana Appellate Courts for the 1977-1978 Term,
39 La. L. Rev. 705 (1979).
```

### Commentaries and Other Special Designations (Rule 16.7.4)

"Commentary," "Tribute," "In Memoriam," "Response," "Dedication," etc. go in roman **after the
author's name but before the title**; where the author is unnamed or the journal's editors are
listed as authors, the designation begins the citation. "Commentary" is not "Comment" (16.7.1).
```
Alvin C. Warren, Jr., Commentary, Financial Contract Innovation and Income Tax Policy, 107 Harv.
L. Rev. 460 (1993).
```

### Multipart Articles, Annotations, Institutes, Newsletters (Rules 16.7.5-.8)

```
Harlan F. Stone, The Equitable Rights and Liabilities of Strangers to a Contract (pts. 1 & 2),
18 Colum. L. Rev. 291 (1918), 19 Colum. L. Rev. 177 (1919).
Claudia Catalano, Annotation, Unlawful Access Under Stored Communications Act, 18 U.S.C.A. § 2701
et seq., 1 A.L.R. Fed. 3d Art. 1 (2015).
Recent Grants, FCD Update (Found. for Child Dev., New York, N.Y.), Dec. 1990, at 1, 7.
```
Newsletters follow 16.5, except that a parenthetical after the publication's title gives the issuing
group and its location.

### Online-Only and Database Journals (Rule 16.8) (22e pp. 174-75)

Where a print version is accessible, cite the print source. Where print is difficult or impossible
to obtain, or the governing authority has designated the electronic source as official, cite the
electronic source with attention to rule 18's authentication principles. A periodical available
**only** online is cited directly per rule 18.2.2. **If the digital source has a DOI, the DOI may be
appended in brackets at the end of the citation as a rule 18.2.1(d) archival tool.**
```
Randy Kommey & Madeleine Fombad, Strategies for Knowledge Sharing Among Rice Farmers: A Ghanaian
Perspective, 21 Elec. J. Knowledge Mgmt. 114 (2023), https://... [https://doi.org/10.34190/ejkm.21.2.2803].
```
For a commercial database, give a complete rule 16 citation plus the database and its unique
document identifier:
```
T.R. Fehrenbach, TV's Alamo Tale Fairly Accurate, S.A. Express-News, Mar. 17, 1996, at A1, 1996 WL 2824823.
```

### Forthcoming Articles (Rule 17.3) (22e pp. 179-80)

Cite as the published piece would be cited, with the same typefaces, except: (i) **no pincite after
the journal or book title**; (ii) add "forthcoming" in the date parenthetical; (iii) include the
month of publication if available. Omit the volume number if not yet available.
```
Aadir A.I. Khan, Comment, From Historical to Cutting-Edge: Equity Receiverships as a Tool to
Resolve Mass Torts, 172 U. Pa. L. Rev. (forthcoming July 2024).
```
To cite a particular page, add a second parenthetical with the manuscript page and a third with the
document's location:
```
F. Brandon Baer & James M. Feldman, We're Low on Vermouth ..., 1 J.L. & Oppression (forthcoming
2001) (manuscript at 3) (on file with authors).
```

## Newspapers (Rule 16.6) (22e pp. 168-70)

Newspapers follow rule 16.5 with **three exceptions** (16.6(a)):

1. Where appropriate, designate the work "Editorial," "Opinion," or "Letter to the Editor," in
   ordinary roman, after the author's name but before the title — or at the beginning if there is no
   author. Substitute the designation for the title where no separate title is given.
2. **After the date**, give the section designation in a parenthetical if needed to identify the page
   unambiguously.
3. Give **only the first page** of the piece; do not indicate the location of specific material.

```
Ari L. Goldman, O'Connor Warns Politicians Risk Excommunication over Abortion, N.Y. Times,
June 15, 1990, at A1.
Nancy Reagan, Editorial, Just Say "Whoa," Wall St. J., Jan. 23, 1996, at A14.
William J. Clinton, Opinion, AIDS Is Not a Death Sentence, N.Y. Times, Dec. 1, 2002 (§ 4), at 9.
```

**Typeface:** the newspaper name is in **SMALL CAPS**, not italics (rule 16.1).

**Place of publication (16.6(b)):** include it in ordinary roman in parentheses after the newspaper's
name if not clear from the name — `Times (London)`, `Chron. Higher Educ. (D.C.)`.

**Consecutively paginated newspapers (16.6(c)):** cite per rule 16.4.

**Wire services (16.6(d)):** cite to a print newspaper, a commercial database, or a webpage. Include
the wire service's name (in small capitals) **only if the citation is to the wire service itself**.

### Online Newspaper Articles (Rule 16.6(f))

Online newspapers may be used in place of print. Cite the online source directly per rule 18.2.2.
Pagination may be included if available but is not necessary. Include the time of posting if
available.
```
John M. Broder, Geography Is Dividing Democrats over Energy, N.Y. Times (Jan. 27, 2009),
http://www.nytimes.com/2009/01/27/science/earth/27coal.html (on file with author).
```

### Magazines (Rule 16.5)

Rule 16.5's own magazine examples:
```
Barbara Ehrenreich, Iranscam: The Real Meaning of Oliver North, Ms., May 1987, at 24, 24.
Damages for a Deadly Cloud: The Bhopal Tragedy Will Cost Union Carbide $470 Million, Time,
Feb. 27, 1989, at 53.
```
Magazine names, like all periodical names, are in **SMALL CAPS** (rule 16.1).

### Blogs and Online Sources (Rule 18.2 — The Internet) (22e pp. 185-90)

Rule 18.2 has **only 18.2.1 and 18.2.2**; there is no 18.2.4. A blog is governed by 18.2.2(b), and
which subpart applies turns on whether the blog is its own site or a subdivision of a larger one.

**Blog that is its own site (18.2.2(b)(i), "main page titles").** "The citation should always include
the homepage or domain name of which the particular citation is a part, referred to here as a 'main
page title.' The website's main page title should be cited using **small capitals**. Capitalization
should conform to the title as it appears on the site. Main page titles should be abbreviated in
accordance with tables T6, T10, and T13":
```
SCOTUSblog, http://www.scotusblog.com/ (on file with the Columbia Law Review) (last visited Oct. 6, 2023).
```

**Blog inside a larger site (18.2.2(b)(ii)).** "If the cited source is published under the name of a
blog or other subdivision that has its own content and presence within a larger web-based source,
**both the name of the site and the name of the subdivision should be included. Titles for
subdivisions should be preceded by a colon.**" Capitalize per rule 8 (22e pp. 96-99) even where the
title bar does not. Note the split within rule 8 itself: 8(a) governs headings and titles generally,
while **8(b)** governs internet material — "In both text and footnotes, capitalize URLs and words in
an internet main page title in accordance with the actual capitalization of the source" — which is
the source of 18.2.2(b)(i)'s conform-to-the-site instruction above.
```
[Author], [Title], [Site]: [Blog] ([Date], at [hh:mm TZ]), [URL] [[archive URL]].
```

```
Randy E. Barnett, What the Declaration of Independence Said and Meant, Reason: Volokh Conspiracy
(July 4, 2024, at 10:13 ET), https://reason.com/volokh/2024/07/04/... [https://perma.cc/C32D-SH5C].

Ella Wiley, Unraveling the Many Costs of Discriminatory Redistricting, Legal Def. Fund: Blog
(Oct. 30, 2023), https://www.naacpldf.org/the-cost-of-discriminatory-redistricting/ [https://perma.cc/SL7D-Y58H].
```
Rule 18.1(a)'s own row for "Dynamic websites, such as blogs, within larger websites" is in the same
form: `Michael J. Coren, The World Needs a New Way to Talk About Heat, Wash. Post: Green Living
(July 25, 2023, at 06:30 ET), ... [https://perma.cc/3QFZ-27RZ].`

**Archiving** is required by 18.2.1(d) for all cited online content, by either of two methods. Where
an archival tool is used, its URL goes in brackets; where a copy is saved instead, an "(on file
with ...)" parenthetical follows the URL and there is no bracketed URL at all.
The timestamp is **recommended** — 18.2.2(c): "It is recommended that citations for web-based sources
include a timestamp whenever possible," in twenty-four-hour format with a time-zone designation.

**Descriptive titles (18.2.2(b)(iii)):** where the page's own headings are not clear enough, supply a
descriptive title — and **do not italicize** it (`Archive of Columns by Pete Wells, N.Y. Times, ...`).

In the 22e, 18.3 is **AI-Generated Content** (22e p. 191) and social media has its own rule at
**18.10** (22e pp. 198-201).

## Restatements, Model Codes, and Uniform Acts (Rule 12.9.4) (within 12.9 Special Citation Forms, 22e pp. 135-39)

Model codes, principles, restatements, standards, sentencing guidelines, and uniform acts are cited
**in small capitals**, by section, rule, or other subdivision. For restatements, give the year the
restatement was published; for model codes, principles, standards, and guidelines, give the year of
adoption, and where amended, the year of the **last amendment** even when citing an unamended
portion. Abbreviate names per table T6. **Indicate the author's name parenthetically**, abbreviated
per rule 15.1(c).

```
Restatement (Third) of Unfair Competition § 3 (A.L.I. 1995).
Principles of the L. of Fam. Dissolution: Analysis and Recommendations § 2.07 (A.L.I. 2002).
U.S. Sent'g Guidelines Manual § 2D1.1(c) (U.S. Sent'g Comm'n 2021).
```

The 22e institutional-author abbreviation is **"A.L.I."**, not "Am. L. Inst.", and **"A.B.A."**, not
"Am. Bar Ass'n".

**Subtitles are retained:** `Restatement (Third) of Prop.: Wills and Donative Transfers § 2.1 (A.L.I. 1999).`

**Drafts:** indicate the fact parenthetically as it appears on the publication, with the draft number
if available and the year.
```
Restatement (Second) of Torts § 847A (A.L.I., Tentative Draft No. 17, 1974).
Model Land Dev. Code § 2-402(2) (A.L.I., Proposed Official Draft 1975).
```

### Comments and Illustrations

Comments, notes, and other addenda are cited per rule 3.4:
```
Restatement (Second) of Conflict of L. § 305 cmt. b, illus. 1 (A.L.I. 1977).
Restatement (Second) of Conts. ch. 16, topic 3, intro. note (A.L.I. 1981).
Unif. Prudent Inv. Act § 2 cmt. (Unif. L. Comm'n 1994).
```

### Uniform Acts

When citing a uniform act **itself**, and not as the law of a particular state, cite it as a separate
code with the author parenthetically. Give the year of the last amendment even if the cited section
was not amended then.
```
U.C.C. § 2-314 (A.L.I. & Unif. L. Comm'n 1977).
Unif. Tr. Code § 105 (Unif. L. Comm'n 2000).
```
When citing to the **Uniform Laws Annotated**, give the act's title (T6), section, year of amendment
or repeal if any, U.L.A. volume, page, and year of publication:
```
Unif. Adoption Act § 10, 9 U.L.A. 45 (1988).
```
When citing to the law of a particular state, cite that state's code: `Okla. Stat. tit. 12A,
§ 2-314 (2004).`

### ABA Professional Responsibility Materials (Rule 12.9.5)

The Model Code of Professional Responsibility and the Model Rules of Professional Conduct are cited
per 12.9.4:
```
Model Rules of Pro. Conduct r. 1.15 cmt. (A.B.A. 1983).
Model Code of Pro. Resp. Canon 2 (A.B.A. 1980).
Model Code of Pro. Resp. EC 7-36 (A.B.A. 1980).
Model Code of Pro. Resp. DR 8-101 (A.B.A. 1980).
```
Ethics opinions are cited by issuing body, opinion number, and year, abbreviated per T6; the subject
may be given parenthetically:
```
A.B.A. Comm. on Ethics & Pro. Resp., Informal Op. 1414 (1978).
```

**Note:** "supra" and "hereinafter" **may not** be used for restatements, model codes, or regulations
except in extraordinary circumstances such as an extremely long name (rule 4.2, 22e pp. 85-87).

```
Good-Faith Bargaining, Black's Law Dictionary (9th ed. 2009).
```

```
The Federalist No. 23 (Alexander Hamilton).
```

## Electronic Databases and Online Sources for Books (Rule 15.9) (22e pp. 162-63)

**Commercial databases (15.9(a)):** give a complete rule 15 citation plus a citation to the database,
including the database's unique identifier or code. Where a source is in both print and a database,
the database citation may be supplied.
```
Abbey G. Hairston, Leave and Disability Coordination Handbook ¶ 110 (2009), Westlaw LDCHBK.
25 Am. Jur. 2d Elections § 100, Westlaw (database updated May 2014).
```

**Internet (15.9(b)):** books found online may differ in format from print, so the two are **not**
interchangeable unless the online source is an exact copy under rule 18.2.1(a). A book or report
available only online is cited directly per rule 18.2.2.

**Ebooks (15.9(c)):** print versions are authoritative; cite an ebook **only if it is the sole media
through which the book is available**. Place an "(ebook)" parenthetical after the date. Where the
ebook uses location numbers rather than pages, use "loc.".
```
Anne Umland & Blair Hartzell, Picasso: The Making of Cubism 1912-1914, at 25 (2014) (ebook).
Ronald Collins & David Skover, When Money Speaks loc. 2992 (2014) (ebook).
```

## Unpublished and Forthcoming Sources (Rule 17) (22e pp. 176-81)

Cite unpublished materials not scheduled for publication by author; title or description; page(s) if
applicable; the **most precise writing date available**; and, if possible, where the work can be
located. **Use ordinary roman type.** If unpublished materials are later collected and published,
cite per rule 23.

### Manuscripts (Rule 17.2.1)

Author's full name (per 16.2), title as it appears on the title page (capitalized per rule 8(a), 22e
pp. 96-99),
subtitle only if particularly relevant, full date in parentheses after the title or pincite, then
parentheticals stating that the work is unpublished and where it can be found.
```
Anatoliy Bizhko, Capitalism and Democracy 25 (Feb. 29, 2000) (unpublished manuscript) (on file with author).
```
Student comments and notes written under faculty supervision but not selected for publication use
the same form, with the second parenthetical naming the type of work ("unpublished comment").

### Working Papers (Rule 17.4) (22e p. 180)

The parenthetical gives the **sponsoring organization, the working paper designation and number, and
the year**, with institutional entities abbreviated per 15.1(e). An unnumbered working paper is
cited per 17.2.1 instead.
```
Alan J. Auerbach & Laurence J. Kotlikoff, National Savings, Economic Welfare, and the Structure of
Taxation 24-33 (Nat'l Bureau of Econ. Rsch., Working Paper No. 729, 1981).
Richard Briffault, The Political Parties and Campaign Finance Reform 16-17 (Columbia L. Sch. Pub. L.
Working Paper, Paper No. 012, 2000), http://papers.ssrn.com/sol3/papers.cfm?abstract_id=223729.
```

### Dissertations and Theses (Rule 17.2.2)

Same form as an unpublished manuscript, **with the date parenthetical first**, then a parenthetical
naming the type of work and the degree-granting institution, then the location.
```
Barbara G. Ryder, Incremental Data Flow Analysis Based on a Unified Model of Elimination
Algorithms (Aug. 15, 1982) (Ph.D. dissertation, Rutgers University) (on file with author).
Ambrogino Guisti, The Green Press ... (Aug. 8, 2007) (B.A. thesis, University of Washington)
(on file with the Suzzallo and Allen Libraries, University of Washington).
```

### Letters, Memoranda, and Press Releases (Rule 17.2.3)

Identify the nature of the document and give the writer and addressee (if any) by name, title (if
relevant), and institutional affiliation (if relevant), abbreviated per tables T6, T10, T11, and T13.
```
Letter from Burke Craighead, Bluebook Ed. Chair, Harv. L. Rev., to Varsha Midha, Bluebook Bus.
Chair, Harv. L. Rev. (June 9, 2024) (on file with the Harvard Law School Library).
Press Release, Screen Actors Guild, Screen Actors Guild Hails Passage of California Privacy Law
(Sep. 30, 1998) (on file with author).
```
For a letter written to the author of the citing work, omit the addressee's name and use "to author."

### E-mail and Listserv Postings (Rule 17.2.4)

Analogize to unpublished letters. The date and timestamp may be needed for identification; archival
information may be included parenthetically and is **recommended**. E-mail addresses of sender and
recipient are not required. "Postings to listservs should follow a similar format, but **should
include** the author's e-mail address and the address of the listserv."
```
E-mail from Mary Miles Prince, Assoc. Dir., Vand. L. Lib., to Edward C. Brewer, III, Assistant
Professor of L., Salmon P. Chase Coll. of L. (Sep. 26, 1999, at 06:15 ET) (on file with author).
Posting of Anastasia Pastan, apastan@act.org, to carall-talk@yahoogroups.com (July 21, 2012)
(on file with author).
```

### Interviews (Rule 17.2.5)

Name, title, and institutional affiliation (if any) of the **interviewee**, and the date. For an
in-person interview, give the location **before** the date. Abbreviate per T6, T10, T11, T13. Where
the author did not personally conduct the interview, name the interviewer.
```
Interview with Jordan Kei-Rahn, Managing Ed., Yale L.J., in New Haven, Conn. (Mar. 2, 2024).
Telephone Interview with John J. Farrell, Senior Partner, Hildebrand, McLeod & Nelson (Nov. 11, 1999).
Interview by Lauren Brook Eisen with Shane Spradlin, CEO, Nextel Commc'ns, in Potomac, Md. (Mar. 1, 2000).
```

### Speeches and Addresses (Rule 17.2.6)

Identify the speaker by name; add title and institutional affiliation if included in the description
or transcript, or if particularly helpful. The title of the speech or address, a pincite where
available, and the date follow. The event is part of that title element, **not** a separate
parenthetical.
```
Bradley Smith, Chairman, Fed. Election Comm'n, Keynote Address at the University of Pennsylvania
Law Review Symposium: The Law of Democracy (Feb. 6, 2004).
Senator Hubert Humphrey, Address at the Harvard Law Review Annual Banquet (Mar. 29, 1958).
```
If transcribed but unpublished, give the transcript's location in a second parenthetical. If
published, use an "in" form per rule 1.6(a)(i).

### Short Forms (Rule 17.6) (22e p. 181)

Use "id." and "supra" as for periodicals (16.9) and nonperiodicals (15.10), substituting the name of
the source for an author where none is listed, and enclosing a manuscript page cite for a
forthcoming publication in parentheses: `See Oetken, supra note 2 (manuscript at 15);`.

## Electronic Sources (Rule 18)

Rule 18 in the 22e runs 18.1 (basic citation forms, 22e pp. 182-84); 18.2 (The Internet, pp. 185-90);
18.3 (AI-Generated Content, p. 191); 18.4 (Electronic Databases, p. 192); 18.5 (Electronic Storage
Media, p. 192); 18.6 (Microform, pp. 192-93); 18.7 (Videographic Media, pp. 193-95); 18.8 (Audio
Recordings and Streaming, pp. 195-97); 18.9 (Images, pp. 197-98); 18.10 (Social Media, pp. 198-201);
18.11 (Hardware and Software, pp. 201-03); 18.12 (Short Citation Forms, pp. 203-04).

### General Principles (Rule 18.2, 18.2.1)

**Prefer print.** "The Bluebook requires the use and citation of traditional printed sources when
available, **unless there is a digital copy of the source available that is authenticated, official,
or an exact copy of the printed source**, as described in rule 18.2.1."

**Cite as if to print, with no URL (18.2.1(a)):** where an authenticated, official, or exact copy is
available online, cite it as the print source "without any URL information appended." Within that
category the Bluebook "prefers citation to an authenticated source, or, if no authenticated source is
available, to a source as proximate to the original as possible" (18.2.1(a)(ii)). Official versions —
a government site or an officially designated source — are "considered, for citation purposes, to be
proximate to the original," and an exact copy (an unaltered copy in a format preserving pagination,
such as a PDF) "is treated **similarly to** an official version" (18.2.1(a)(iii)). Official versions
and exact copies are therefore not ranked against each other.

**Append the URL (18.2.1(b))** in two situations: (i) the traditional source is "so obscure as to be
practically unavailable," or a parallel internet cite "will substantially improve access"; and (ii)
the web source has print characteristics — permanent pages with permanent page numbers plus the
elements of the print genre (volume number, publication date) — in which case cite it per the print
rule and append the URL, "even if it is unknown whether the cited information is available in print."

**Cite directly per 18.2.2** only where the source can be cited under neither 18.2.1(a) nor
18.2.1(b)(ii).

**Order of parentheticals (18.2.1(c)):** the URL follows format-related parentheticals ("alteration in
original," "emphasis added") and related-authority parentheticals ("citing," "quoting"), but
**precedes** explanatory parentheticals — per rule 1.5(b).

### Archival Is Mandatory (Rule 18.2.1(d))

"The Bluebook requires that **all** online content cited or generated by authors be captured and
stored in a permanent setting." Two acceptable methods:

- **Archival tool** — "append the archive URL to the full citation in brackets":
  `..., https://www.theatlantic.com/ideas/archive/2024/08/... [https://perma.cc/PT32-56LR].`
- **Saved copy on file** (e.g. a PDF) — indicate where it can be found in a parenthetical *following*
  the URL: `..., https://www.nytimes.com/2024/07/20/... (on file with the Columbia Law Review).`

A DOI may serve as that bracketed archival tool (rule 16.8's example appends
`[https://doi.org/10.34190/ejkm.21.2.2803]`).

The archive URL is an **addition** to the source URL, never a replacement for it.

### URL Format (Rule 18.2.2(d)-(g))

The URL "should point readers directly to the source cited rather than to an intervening page of
links." In order:

1. If a **shortlink** clearly indicating the source of the site exists (e.g. `wapo.st`, `imdb.to` —
   **but not** a generic shortener such as `bit.ly`), cite the shortlink.
2. If no shortlink is available and the full URL is straightforward, cite the entire URL as it
   appears in the browser's address bar.
3. **Alternatively, use the site's root URL** if (1) the URL is "long, unwieldy, or full of nontextual
   characters (such as question marks, percentage signs, or ampersands)," or (2) the source can be
   obtained only by submitting a form or query. Where the root URL is used and the site's format is
   not clear from the rest of the citation, add a **clarifying parenthetical** explaining how to reach
   the specific information:
```
http://fjsrc.urban.org/noframe/wqs/q_data_1.htm#2001 (choose "2001" from dropdown; then choose
"Defendants in Criminal Cases-Administrative Office of the U.S. Courts (AOUSC)"; then click "out"
and "submit"; then follow "TTSECMO" hyperlink).
```

Some URLs are case sensitive — cite them as they appear in the browser. Where a site is served by
several URLs, use the **primary** one, not an alternate server (18.2.2(e)). Where a document exists
both in a paginated format (PDF) and one that is not, **always cite the paginated one** (18.2.2(f)),
and give pinpoint cites to the numbers printed on the document itself, never "screen numbers"
(18.2.2(g)).

### Date, Time, and "Last Visited" (Rule 18.2.2(c))

Give the date **as it appears on the site**, after the main page title and any pinpoint. If the
resource has been updated or corrected on a later date, use that date instead of the original
publication date.

"**When material is otherwise undated**, the date that the website was last visited should be placed
in a parenthetical after the URL":
```
Yahoo!, http://www.yahoo.com [https://perma.cc/94S2-LKJW] (last visited Aug. 12, 2024).
```
"Last visited" is the **undated-source** device — not a volatility flag. Volatility is handled by the
mandatory archiving of 18.2.1(d). Where the archival tool records an archive date, put **that** date
in the "last visited" parenthetical.

Timestamps are recommended "whenever possible," in twenty-four-hour format with a time-zone
designation taken from the source (or from the accessing device if the source gives none); where the
zone is a daylight-savings subdivision, use the larger designation. They are "especially encouraged"
for a comment to a posting.

## Short Forms for Secondary Sources (Rules 4, 15.10, 16.9)

### Id. (Rule 4.1) (22e pp. 83-85)

In law review footnotes, use "id." when citing the immediately preceding authority within the same
footnote, or within the immediately preceding footnote **when that footnote contains only one
authority**. In court documents and legal memoranda, use "id." for the immediately preceding
authority only when that citation contains a single authority. **The period at the end of "id." is
always italicized.** If the first citation refers only to a shorter work contained within an
authority, do not use "id." for a later citation to the entire authority — use "supra."

Rule 4.1's own examples (footnote numbers as the Bluebook prints them):
```
8 Fleming James, Jr. & Geoffrey C. Hazard, Jr., Civil Procedure §§ 1.3-.5 (3d ed. 1985).
9 See id. § 1.7.
```
And its counterexample, where the preceding footnote cites more than one source:
```
16 See Robert B. Reich, Toward a New Consumer Protection, 128 U. Pa. L. Rev. 1 (1979); Note,
   Direct Loan Financing of Consumer Purchases, 85 Harv. L. Rev. 1409, 1415-17 (1972); see also
   Chalfin v. Specter, 233 A.2d 562 (Pa. 1967).
17 See Chalfin, 233 A.2d at 570.        [Not: 17 See id. at 570.]
```

### Supra (Rule 4.2(a)) (within 4.2 "Supra" and "Hereinafter", 22e pp. 85-87)

**Form:**
```
[Author's last name], supra note [#], at [Page].
```

Use the **full institutional name** for an institutional author; where no author is cited, use the
title of the work; for unsigned student-written law review materials, use the designation (16.7.1(b)).
Give the footnote of the full citation **unless the full citation is in the same footnote**, in which
case use "supra" with no cross-reference. Rule 4.2(a) itself adds only that "[v]olume, paragraph,
section, page numbers, or timestamps may be added to refer to specific material"; the mandatory
pincite comes from **16.9(b)** — "In using a 'supra' form, always indicate the page or pages cited
except when citing the work in its entirety."

Rule 4.2(a)'s own examples:
```
27 Reich, supra note 16, at 6.
29 2 Holdsworth, supra note 10, at 6.
31 Keeton et al., supra note 30, § 2, at 4; Note, supra note 16, at 1416.
```

Capitalize the last name in a "supra" form per **rule 8(c)** (22e pp. 96-99): "Capitalize authors'
last names as they are given in either the table of contents of a periodical or on the title page of
a work, whichever more clearly indicates the proper capitalization of the author's name." The rule
gives both forms, joined by "or," and the source decides between them:
```
14 van Dorn, supra note 12, at 151.
14 Van Dorn, supra note 12, at 151.
```

**Never use "infra"** to refer to books, reports, or other nonperiodic materials (rule 15.10, 22e
pp. 163-64).

For materials available **only online**, use the normal short form for the source; a URL need not be
repeated after a full citation (rules 15.10, 16.9, 17.6).

### Hereinafter (Rule 4.2(b))

Define in the first citation, **after the citation but before any explanatory parenthetical**, in
brackets. The shortened form appears in the same typeface as in the full citation. Do **not** use
"hereinafter" where a simple "supra" form is adequate; **do** use it to distinguish two authorities
in the same footnote where "supra" would confuse.
```
42. See Edward B. Rock, Saints and Sinners: How Does Delaware Corporate Law Work?, 44 UCLA L.
    Rev. 1009, 1016-17 (1997) [hereinafter Rock, Saints and Sinners]; Edward B. Rock, The Logic
    and (Uncertain) Significance of Institutional Shareholder Activism, 79 Geo. L.J. 445 (1991)
    [hereinafter Rock, Shareholder Activism].
43. See Rock, Saints and Sinners, supra note 42, at 1019.
```

### Works in Collection (Rule 15.10.1)

"Id." may refer to the **shorter work** if it was the immediately preceding authority in the same
footnote or the sole authority in the immediately preceding footnote. **Do not use "id." to refer to
the collection as a whole when citing another shorter work within it** — use a "supra" form, which
for the entire volume takes the **title of the collection** (not an author), regardless of whether
the collected pieces have one author or many. The "supra" form for an individual shorter work takes
the author's last name, or the title if there is no author.

## Special Source Types

### Briefs, Court Filings, and Transcripts (Rule 10.8.3) (within 10.8 Special Citation Forms, 22e pp. 117-21)

The full name of the document **as it appears on the filing** comes first, abbreviated per rule
10.2.1(c), then a pinpoint cite if any, then the full case citation and the docket number. Where no
decision has been rendered, the parenthetical date is the filing date. **Always include the docket
number** — parenthetically where there is a reported citation, or as the citation where there is not.

```
Complaint at 17, Kelly v. Wyman, 294 F. Supp. 893 (S.D.N.Y. 1968) (No. 68 Civ. 394).
Brief of Petitioner-Appellant at 48, United States v. Al-Marri, No. 03-3674 (7th Cir. Nov. 12, 2003).
```

The court-assigned document number (e.g. from PACER) may be included but is unnecessary unless
essential to finding the document: `..., Dkt. No. 14.`

**Amicus briefs** follow the same rules, with the sole exception that "et al." may be used where
there are more than two signatories.

Rule 10.8.3 gives a multi-district-litigation example:
```
Plaintiff's Motion for Summary Judgment at 2, In re 3M Combat Arms Earplug Prods. Liab. Litig.,
No. 20-CV-47213 (N.D. Fla. July 7, 2022).
```

### Transcripts

Court-produced documents, including oral argument transcripts and transcripts of record, follow the
same general rules:
```
Transcript of Oral Argument at 11, Ayers v. Belmontes, 127 S. Ct. 469 (2006) (No. 05-493).
Transcript of Record at 16-17, Johnson v. Eisentrager, 339 U.S. 763 (1950) (No. 306).
```

A parallel citation to an electronic database or website may be added if helpful, and must include a
pinpoint cite to the database where one is required for the primary document, and vice versa.

| Blog as a subdivision of a larger site | Site name, then colon, then subdivision name | 18.2.2(b)(ii) |
| Descriptive title supplied by the author for a webpage | Roman — **not** italicized | 18.2.2(b)(iii) |

## Common Errors

### Article Citations

| Error | Correction |
|-------|------------|
| Missing journal abbreviation periods | Harv. L. Rev. (not Harv L Rev) |
| Wrong year placement | ...873 (1987). (not ...873, 1987.) |
| Missing pinpoint | Give the page or pages cited — **except** when citing the work in its entirety (16.9(b)), and **not** after the journal or book title of a forthcoming work (17.3) |
| Periodical name italicized | Periodical names — journal, magazine, newspaper — are SMALL CAPS (16.1) |
| Student designation after the title | The designation precedes the title (16.7.1(a)) |
| "Book Review" for a student review | Student reviews use "Book Note" regardless of the journal's label (16.7.1(c)) |

### Book Citations

| Error | Correction |
|-------|------------|
| Publisher included | 15.4 requires it only under 15.4(a)(iii) (edition not by the original publisher) and 15.4(d) (pre-1900); the 15.4(a)(i)-(ii) examples carry none |
| First edition noted | Omit "1st ed." |
| Missing year | Year required except where 15.8(b) permits omitting the date and edition (standardized pagination, e.g. `2 William Blackstone, Commentaries *152, *155-56.`), where 15.8(c)(i) governs (an entire Federalist paper: `The Federalist No. 23 (Alexander Hamilton).`), or where 15.4(d) applies and no date is available ("n.d.") |
| "et al." for three authors | "et al." only above three; two or three authors are all listed (15.1(a)-(b)) |
| "Dr." / "Prof." / "Judge" / "Justice" retained | Omit the honorific even if on the title page (15.1) |
| Subtitle always included | Include only if particularly relevant (15.3) |

### Restatement and Model Code Citations

| Error | Correction |
|-------|------------|
| "Am. L. Inst." as the author | The 22e abbreviation is "A.L.I." (12.9.4) |
| "Am. Bar Ass'n" as the author | "A.B.A." (12.9.4-.5) |
| supra / hereinafter for a restatement or model code | Not permitted absent extraordinary circumstances (4.2) |

### Short Form Errors

| Error | Correction |
|-------|------------|
| Supra without note number | Reich, supra note 16, at 6 (4.2(a)) |
| Id. after intervening cite | Use supra form instead |
| Wrong author name | Last name only for supra; **full** name for an institutional author (4.2(a)) |
| "id." to the whole collection after citing a shorter work in it | Use supra with the collection's title (15.10.1) |
| infra for a book or report | Never permitted (15.10) |

## Verification Checklist

Before finalizing secondary source citations:

- [ ] Author name(s) correctly formatted; honorifics dropped; "et al." used only above three authors
- [ ] Title matches source exactly; subtitle only if particularly relevant
- [ ] Periodical abbreviation checked against T13 first, then T6 and T10 for any word T13 omits
- [ ] Volume and page numbers verified
- [ ] Edition and year included; latest edition cited
- [ ] Pinpoint provided for specific propositions
- [ ] Typeface correct for source type (periodical names in small caps, not italics)
- [ ] Short forms reference correct footnote number
- [ ] Every online source archived (18.2.1(d)) — mandatory, not optional; bracketed archive URL if an
      archival tool was used, `(on file with ...)` after the URL if a copy was saved
- [ ] "Last visited" parenthetical used where the material is otherwise undated — and carrying the
      archival date instead where an archival tool records one (18.2.2(c))
