# Навык: Транскрипция видео

Следуй шагам последовательно. Шаги 1–2 — вызов инструментов через ShellTool. Шаги 3–5 — твоя работа своим интеллектом.

---

## Что спросить у пользователя (если не указано)
- Путь к файлу (видео или аудио)
- Опционально: язык, движок транскрипции

---

## Шаг 1: Извлечение аудио

```bash
python tools/extract_audio.py "{путь_к_файлу}"
```

Флаги при необходимости:
- `--normalize` — тихий звук
- `--denoise` — шумное видео
- `--job-id my_id` — задать конкретный ID

Ожидаемый вывод (stdout):
```json
{
  "job_id": "a1b2c3d4",
  "audio_path": "output/a1b2c3d4/audio.wav",
  "duration_seconds": 3610.5,
  "duration_formatted": "1:00:10"
}
```

Запомни `job_id` и `audio_path`.

Коды ошибок: `1` = файл не найден, `2` = нет аудио, `3` = ошибка FFmpeg.

---

## Шаг 2: Транскрипция

```bash
python tools/transcribe.py "{audio_path}"
```

Флаги при необходимости:
- `--engine groq` — другой движок
- `--engine faster_whisper --model-size small` — мало памяти
- `--language ru` — если язык определился неверно

Вывод: в `stderr` — сводка, в `stdout` — путь к `transcript_raw.json`.

### Таблица движков:
| Движок | Флаг | Нужен ключ | Скорость | Качество |
|---|---|---|---|---|
| faster-whisper | `--engine faster_whisper` | Нет | Хорошая | Хорошее |
| Groq | `--engine groq` | GROQ_API_KEY | Очень быстро | Хорошее |
| OpenAI | `--engine openai` | OPENAI_API_KEY | Быстро | Отличное |
| WhisperX | `--engine whisperx` | Нет | Медленнее | Отличное |

---

## Шаг 3: Читаем транскрипцию

Прочитай `output/{job_id}/transcript_raw.json`.

Обрати внимание:
- `meta.language` — определился ли язык правильно
- `segments` — массив с таймкодами
- `confidence < 0.7` — ненадёжные сегменты, отметить `[?]`

---

## Шаг 4: Редактура и анализ (твоя работа)

### 4А. Редактура текста

Что исправлять:
- Ошибки ASR: "в общем то" → "в общем-то", "какбы" → "как бы"
- Омонимы: "питон" в IT-контексте → "Python"
- Слипшиеся слова, ошибки в именах собственных
- Числа: "два тысяча двадцать пять" → "2025"

Что расставлять: точки, запятые, тире, вопросительные знаки.

Что НЕ делать: не менять смысл, не добавлять слова, не убирать разговорный стиль.

Группировка:
- Объединяй короткие сегменты (< 2 сек) с соседними
- Разбивай на абзацы по смене темы
- Каждый абзац: `[HH:MM:SS] Текст.`
- Ненадёжный сегмент: добавить `[?]` после текста

### 4Б. Анализ содержания

- **Резюме**: 3–5 предложений, суть материала
- **Ключевые тезисы**: 5–10 штук, каждый с таймкодом, важность 1–5
- **Оглавление**: логические разделы, таймкод + длительность
- **Топики**: 3–7 тегов

---

## Шаг 5: Запись файлов (WriteFileTool)

Записать три файла в `output/{job_id}/`:

### `transcript_clean.txt`
```
[00:00:00] Первый абзац транскрипции.

[00:00:52] Второй абзац.
```

### `transcript_clean.srt`
```
1
00:00:00,000 --> 00:00:06,800
Первое предложение.

2
00:00:07,000 --> 00:00:14,500
Второе предложение.
```
Правила: номер с 1, пустая строка между блоками, строки ≤ 80 символов, таймкод формат `HH:MM:SS,mmm`.

### `report.md`
```markdown
# 📄 [Имя файла]

**Движок**: [engine] [model] | **Язык**: [language] | **Длительность**: [duration] | **Слов**: ~[count]

---

## 📝 Резюме
[3–5 предложений]

---

## 🔑 Ключевые тезисы
| Время | Тезис | Важность |
|---|---|---|
| [00:03:12] | Текст тезиса | ⭐⭐⭐⭐⭐ |

---

## 📋 Оглавление
| Время | Раздел | Длительность |
|---|---|---|
| [00:00:00] | Введение | ~3 мин |

---

## 🏷️ Топики
`тег1` `тег2` `тег3`

---

## 📄 Транскрипция
[вставить весь transcript_clean.txt]
```

---

## Шаг 6: Сообщи пользователю

```
✅ Транскрипция завершена

Файлы сохранены в output/{job_id}/:
  📄 transcript_clean.txt  — текст с таймкодами
  🎬 transcript_clean.srt  — субтитры
  📊 report.md             — отчёт с резюме и оглавлением

Движок: {engine} {model} | Длительность: {duration}
```

Если были `[?]` сегменты — добавить предупреждение с количеством.

---

## Специальные случаи

**Другой движок**: `"перетранскрибируй с движком groq"` → Шаг 2 с флагом, повторить 3–5.

**Только часть**: `"первые 30 минут"` → обрабатывать сегменты до `start < 1800`.

**Перевод**: после 4А перевести текст, добавить секцию `## 🌍 Перевод` в report.md.

**Кеш**: если `transcript_raw.json` уже есть — спросить пользователя, использовать кеш или переделать.
