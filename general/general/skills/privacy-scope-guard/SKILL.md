# Skill：隐私与范围守门

## 事项记忆要求

- 本技能是分析镜头。默认把结果写入会话回复、`matter.md` 或目标交付文件。
- 只有长期协作、审计追踪或用户明确要求时，才更新 `skill_outputs.md`。
- 如果本技能没有实际执行，不能在报告中暗示已完成；如果信息不足，输出缺口、影响和下一步。


## 适用场景

在用户开始描述纠纷、上传材料、请求策略、要求起草文书、要求设计提问或请求评估胜算之前，优先使用本技能。

## 目标

1. 防止泄露个人隐私和案件敏感信息。
2. 明确法域、案件类型、程序阶段和用户目标。
3. 识别时效、期限、证据灭失、刑事/行政风险等高风险点。
4. 过滤违法、危险或不当请求。
5. 为后续技能提供安全、清晰的输入边界。

## 输入

- 用户的初始描述。
- 用户上传的证据或材料摘要。
- 用户希望达成的目标。
- 已知的法律程序阶段。

## 工作流

### 1. 脱敏检查

识别并建议脱敏以下信息：

- 姓名、身份证号、护照号、出生日期。
- 手机号、邮箱、住址、工作单位。
- 银行账号、支付账号、订单号、合同编号。
- 未成年人信息。
- 商业秘密、内部系统账号、聊天记录中的无关第三人信息。

输出时使用：

- “甲方/乙方/对方/第三人”
- “某日期/某金额/某地址”
- “证据 A/证据 B”

### 2. 范围确认

检查以下字段是否明确：

| 字段 | 说明 |
|---|---|
| 法域 | 中国大陆、香港、美国某州等 |
| 纠纷类型 | 合同、劳动、侵权、消费、租赁、公司、婚姻家事等 |
| 程序阶段 | 咨询、谈判、投诉、诉前、起诉、答辩、庭审、执行 |
| 用户身份 | 原告/被告/申请人/被申请人/投诉人/被投诉人/第三人 |
| 用户目标 | 要钱、解除合同、道歉、恢复权利、停止侵害、降低损失等 |
| 期限 | 诉讼时效、仲裁期限、答辩期限、上诉期限、投诉期限等 |

如缺失，不必机械追问全部；优先标记会直接影响结论的缺口。

### 3. 高风险识别

标记以下风险：

- 诉讼时效或程序期限可能临近。
- 对方可能转移财产或证据灭失。
- 用户可能承担刑事、行政、名誉、职业资格风险。
- 用户计划使用非法取证、威胁、骚扰或公开曝光。
- 涉及未成年人、家庭暴力、重大人身安全。
- 涉及重大金额或不可逆损失。

### 4. 不当请求过滤

如果用户要求以下事项，必须拒绝该部分，并给出合法替代方案：

- 伪造、篡改、隐藏、销毁证据。
- 教别人说假话或诱导对方作虚假陈述。
- 通过非法录音、偷拍、黑客、盗号、定位、跟踪等方式取证。
- 威胁、骚扰、公开隐私、恶意举报。
- 编造案例、法条、判决书或律师函内容。

## 输出格式

```markdown
## 范围与隐私检查
- 已脱敏/建议脱敏：
- 法域：
- 类型：
- 阶段：
- 用户目标：
- 关键期限：

## 当前可分析范围

## 必须补充或核验的信息
1. 
2. 

## 高风险提醒
- 风险：
- 原因：
- 安全替代：
```

## 质量检查

- 没有泄露不必要的个人信息。
- 没有假定未确认事实。
- 没有越权给出确定法律结论。
- 对高风险行为给出合法替代路径。
