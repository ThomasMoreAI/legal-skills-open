# Modules

Chaque module est autonome : sa propre API JavaScript, sa CLI, ses tests, ses sources.

| Module | Sujet | Commande CLI |
|---|---|---|
| [FAIA]({{ site.baseurl }}/modules/faia) | Audit fiscal AED (SAF-T LU 2.01) | `npm run faia` |
| [RTS]({{ site.baseurl }}/modules/rts) | Retenue à la source salaires | `npm run rts` |
| [Bëllegen Akt]({{ site.baseurl }}/modules/bellegen-akt) | Droits enregistrement immo | `npm run bellegen-akt` |
| [eCDF]({{ site.baseurl }}/modules/ecdf) | Déclarations fiscales en ligne | `npm run ecdf` |
| [LBR]({{ site.baseurl }}/modules/lbr) | Registre de Commerce | `npm run lbr` |
| [Templates DE]({{ site.baseurl }}/modules/templates-de) | Documents en allemand | `npm run de` |
| [Banques LU]({{ site.baseurl }}/modules/bank) | Parseurs BCEE/BIL/Spuerkeess/ING | `npm run bank` |
| [Calc]({{ site.baseurl }}/modules/calc) | Impôts (IRC, ICC, IF, IRPP, TVA, succession) | `npm run calc` |
| [Indice STATEC + SSM]({{ site.baseurl }}/modules/statec) | Échelle mobile, indexation, SSM | `npm run statec` |
