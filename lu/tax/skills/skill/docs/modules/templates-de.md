# Templates DE — Documents en allemand

Le Luxembourg est trilingue (français, allemand, luxembourgeois). Certaines administrations et notaires (en particulier dans le nord du pays) attendent les documents en **allemand**. Ce module fournit 6 templates : facture, devis, lettre formelle, attestation, mise en demeure, accusé de réception.

## En CLI

```bash
npm run de -- liste
npm run de -- rendre rechnung exemple.json
```

18 tests dans [`scripts/test-templates-de.js`](https://github.com/gregherbe76/Luxembourg-Paperasse/blob/main/scripts/test-templates-de.js).
