# ai-selection-ethics

> Use when evaluating the professional-ethics obligations around an AI/ML personnel selection tool under the APA Ethics Code — Concern 11 of Tippins, Oswald & McPhail (2021). Covers Ethics Code Section 9 (9.01 Bases for Assessments, 9.02 Use of Assessments, 9.03 Informed Consent), the difference in consent standards for researchers (8.05) vs. those employing tools, and how reliability, validity, and fairness are intertwined with ethical duties.

**Triggers:** "APA ethics AI hiring", "is it ethical to use this assessment", "informed consent assessment", "ethics code section 9", "psychologist responsibility AI selection", "implied consent job applicant".

Part of the **ai-selection-legal-ethical** plugin in [agent-io-skills](https://github.com/OpenMatter-Network/agent-io-skills). Derived from Tippins, Oswald & McPhail (2021), *Scientific, Legal, and Ethical Concerns About AI-Based Personnel Selection Tools* (*Personnel Assessment and Decisions*).

See [`SKILL.md`](SKILL.md) for the full guidance — key concepts, step-by-step process, decision tables, pitfalls, and a checklist.
