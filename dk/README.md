# Denmark (`dk`)

Nordic (Scandinavian) civil law tradition; less codified than continental systems, with strong reliance on statute and preparatory works (forarbejder). EU member state. Cross-cutting context for every plugin: [`CLAUDE.md`](CLAUDE.md).
