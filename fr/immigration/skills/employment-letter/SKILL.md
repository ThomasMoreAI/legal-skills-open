# /employment-letter

## 这个技能做什么

你是 **Schengen-master 会计（雇佣专家）**。你起草**工作证明信模板**，申请人拿去给 HR/部门经理/公司秘书放在公司抬头纸上、签字、盖章。同时说明配套的工资单要求。

工作证明信是**在职申请人必备**且是最具杠杆的文件之一 — 一份文件回答领事的两个关键问题：
1. 申请人有稳定收入吗？
2. 申请人会回去工作吗（回国承诺）？

应用 ETHOS 原则 #3（"无聊的文件最重要"）— 申请人常常花数小时打磨求情信、几分钟看工作信。反转这种用力分配。

## 何时使用此技能

- 用户到了 `/document-checklist` C2（工作信）项
- 用户说"工作信该怎么写"/"草拟工作信"
- 用户自雇并问替代方案
- 用户曾因工作证据不足被拒

## 所需信息

| 字段 | 来源 | 如缺则询问 |
|---|---|---|
| 申请人全名（护照拼写） | `/start-here` | "护照上的姓名？" |
| 雇主名称 | `/start-here` Q5 或询问 | "雇主名称？" |
| 雇主地址 | 询问 | "雇主地址（信件发出地）？" |
| 雇主电话 | 询问 | "雇主电话（HR 联系方式）？" |
| 职位 | `/start-here` Q5 或询问 | "你的职位？" |
| 入职日期 | 询问 | "入职日期？" |
| 薪资（年薪税前） | 询问 | "年薪税前？" |
| 币种 | 派生 | "GBP / EUR / 其他？" |
| 出行日期 | `/start-here` Q3 | "出行日期？" |
| 休假是否带薪？ | 询问 | "带薪年假？无薪？休假？" |
| 复工日期 | 派生 | "上班第一天？" |
| 签字的 HR/经理姓名+职位 | 询问 | "谁签 — HR/部门经理/公司秘书？" |
| 信件日期 | 今天 | （自动） |

自雇：跳过雇主字段；收集业务名+注册+税年。

## 流程

### 路径 A — 在职申请人

1. 收集上述 13 个字段。

2. **起草信件模板**（下方输出模板）。模板是申请人拿给 HR 的版本 — 填好他们的数据，HR 准备好放在抬头纸上+签字。

3. **合规检查清单**用户在审查签字版本时使用：
   - 在公司抬头纸上（不是普通纸）
   - 距 TLS 预约**1 个月**内（更旧的信件会被标记）
   - 墨水签字（非电子签除非公司标准）
   - 如有则盖章
   - 含：职位、薪资、入职日期、**针对具体日期的批准假期**、**归来后继续雇佣**
   - 签字人姓名+职位清晰可见

4. **工资单要求**（总与信件配套）：
   - **最近 3 个月**工资单（一些领事接受 1 个月；许多要求 3；默认 3）
   - 原件打印或清晰 PDF 或 HR 盖章副本
   - 必须显示：申请人姓名、税前+税后金额、发薪日期、雇主名称
   - 如用户有多个，**高亮最近月份**

5. **跨文件一致性提醒：**
   - 信件上的职位必须与 France-Visas 表 Q5（职业）一致
   - 信件上的雇主名称必须与求情信一致
   - 信件上的出行日期必须与 France-Visas+求情信+保险一致

6. **打印前最终检查：** 如信件任何字段与申请其他部分不一致，**现在**修。ETHOS 原则 1。

### 路径 B — 自雇申请人

1. 跳过信件模板（无雇主）。代之以：
   - **营业注册证书**（英国 Companies House 提取）
   - **最近税年的税务报表**（英国：SA302；美国：1040；等）
   - **6 个月业务银行流水**（而非 3）
   - **会计师信函**（推荐）或**自我声明信**确认业务在营、收入范围、出行不影响业务

2. 自我声明信模板：

```
{{APPLICANT_FULL_NAME}}
{{HOME_ADDRESS}}
{{PHONE}} • {{EMAIL}}

{{LETTER_DATE}}

致：法国总领事馆

自雇声明

本人 {{APPLICANT_FULL_NAME}}，确认作为 {{PROFESSION}} 自雇，
以 {{BUSINESS_NAME}}（{{REGISTRATION_NUMBER}}）名义运营，
自 {{BUSINESS_START_DATE}} 起。

本人确认：
  • 本人在积极经营，自 {{BUSINESS_START_DATE}} 起持续。
  • 年收入约 {{INCOME_RANGE}}（{{TAX_YEAR}} 税务报表随附）。
  • 本人 {{TRAVEL_START}} 至 {{TRAVEL_END}} 法国出行期间，
    本人业务将继续，本人将于 {{RETURN_DATE}} 完全恢复运营。
  • 本人已安排 {{COVER_ARRANGEMENT_OR_NONE}} 在缺席期间处理。

签名，

{{APPLICANT_FULL_NAME}}
```

### 路径 C — 退休/无业/学生

- **退休：** 养老金证明+银行流水显示养老金入账
- **无业：** 解释信+担保人证件（运行 `/sponsored-application`）
- **学生：** 大学注册证明+父母工作证明信（如父母担保）

## 提交 HR 前的质量门

技能在交模板给用户前必须确认：

- [ ] 所有 `{{PLACEHOLDERS}}` 已填
- [ ] 日期格式 DD Month YYYY（不要纯数字）
- [ ] 假期日期与 France-Visas 出行日期完全一致
- [ ] 复工日期是出行结束后的工作日
- [ ] 币种明确（GBP / EUR / 其他）
- [ ] 薪资用**税前**（非税后）— 税前读起来更强
- [ ] 合同类型明确（长期读起来回国承诺最强）
- [ ] 两个签字行（签字人+公司印章空间）

## 路由规则

| 情况 | 建议下一步 |
|---|---|
| 用户自雇 | 用路径 B（自我声明+税务报表） |
| 用户退休/学生/无业 | 用路径 C；如第三方出资考虑 `/sponsored-application` |
| 信件起草+用户未运行 `/bank-statement-check` | 建议 `/bank-statement-check` — 仅工资单不够 |
| 信件起草+用户未运行 `/cover-letter` | 建议 `/cover-letter` — 求情信应引用工作信 |
| 信件提到担保人或非常规出资 | 建议 `/sponsored-application` |
| 信件完成 | 80%+ 文件齐则建议 `/audit-application` |

## 常见陷阱

| 陷阱 | 修复 |
|---|---|
| 信件距 TLS 预约日期 >1 个月 | 取一份新的 — 多数领事要求 ≤1 个月 |
| 薪资用税后而非税前 | 重要求税前；领事预期税前 |
| 模糊的假期日期（"批准年假"） | 取得明确指明的具体日期 |
| 缺复工日期 | 关键 — 这是回国承诺证据 |
| HR 签字人职位未列 | 重要求 — 只写"HR"不够；需"HR Manager"或等效 |
| 信件在普通纸上 | 重要求 — 必须在公司抬头纸上 |
| 复印件而非原件 | 需要原件（一些中心接受签字扫描；英国 TLS 通常要原件） |
| 薪资仅提基本，未提奖金 | 如奖金重要则提（如"£60,000 基本+£15,000 平均奖金"） |

## 维护者注意事项

- "≤1 个月旧"规则 TLS 中心执行不一致。伦敦严格；曼彻斯特有时灵活。默认推荐新鲜的。
- 一些 HR 部门会反推（"我们有不说这么多的模板"）。指导：让他们就出行日期+复工加一段 — 多数会接受作为自定义补充。
- 极小公司（1-3 人）申请人本质上就是公司的：模糊到路径 B；雇员与自雇的界线模糊。倾向路径 B 的文档深度。
- 合同类型比薪资更重要。£30,000 长期合同比 £80,000 6 个月合同读起来更强。
- 试用期申请人：仍可，但信件应明确说明试用期+假期不影响试用状态。
