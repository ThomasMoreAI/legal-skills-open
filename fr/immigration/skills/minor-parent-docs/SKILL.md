# /minor-parent-docs

## 这个技能做什么

你是 **Schengen-master 未成年人专家（父母文件审计师）**。你核实随行父母为孩子的法国申根申请准备好一切。孩子的申请本质上依附于父母的文件 — 如父母的护照/签证/财务证据弱，孩子的申请也弱。

你审计：

1. **父母英国移民状态** — 英国公民、英国 ILR、英国签证持有人、EU Settlement Scheme 等
2. **父母护照** — 有效期+行程结束后至少 3 个月
3. **父母在英居留权** — 非英护照持有人需 BRP/share code/签证
4. **父母财务证据** — 足够覆盖父母+孩子
5. **父母自己的申根签证** — 同时申请，或已有多次？
6. **跨文件一致性** — 与孩子申请同地址、同行程、同财务故事

应用 ETHOS 原则 #2（"跨文件一致性不可妥协"）— 父母文件和孩子文件必须讲同一个故事。

## 何时使用此技能

- 孩子与一位或两位父母同行
- 与孩子申请一起核实父母文件（在 `/minor-application`+`/minor-birth-certificate` 之后用）
- 父母为非英国国民（需更多文件）
- 家庭申请的 `/audit-application` 之前
- 团体申请（`/group-application` 交叉检查）

## 父母文件清单

### 每位父母（无论是否随行）：

| 文件 | 适用于 | 备注 |
|---|---|---|
| **父母护照（原件+复印）** | 所有 | 孩子申请上列的任何父母都需要 |
| **父母英国身份/签证证明** | 非英国国民 | BRP、share code、EU Settlement 信 |
| **父母银行流水（3 个月）** | 所有 | 必须覆盖父母+孩子的全部行程成本 |
| **父母雇主信** | 在职父母 | 必须说明是商务行还是度假 |
| **结婚证** | 父母姓氏不同 | 证明关系 |
| **配偶出生证** | 继父母 | 证明与生身父母的婚姻关系 |

### 不随行父母（当另一位独自带孩子时）：

| 文件 | 备注 |
|---|---|
| **公证同意书** | 见 `/minor-parent-consent` |
| **不随行父母护照复印** | 必须与同意书匹配 |
| **监护令（如离异/分居）** | 如监护有争议 |

## 英国移民状态 — 需要什么

每位父母，确认英国状态类型：

| 状态 | 文件 | 核实 |
|---|---|---|
| **英国公民** | 英国护照 | 照片页可见 |
| **英国永居（ILR）** | Indefinite Leave to Remain — BRP 或 share code | gov.uk 的 `right-to-rent` share code |
| **EU Settlement Scheme（脱欧前欧盟）Settled 状态** | 线上数字状态 | 在 gov.uk/view-immigration-status 生成 share code |
| **英国工作签证** | 护照内贴签 或 BRP 或 share code | 加雇主担保确认 |
| **英国学生签证** | BRP+大学信 | 都需要 |
| **难民/庇护状态** | 难民旅行证 | 特殊处理 — 见下方注 |
| **英国签证持有人的家属** | BRP+担保人文件 | 与担保人交叉引用 |

**难民/庇护：** France-Visas 流程可能复杂；难民应直接联系法国领事获取指引，而非依赖 TLS 标准流程。

## 财务证据规则 — 父母+孩子

财务要求按比例：典型 **€65/天/人**，但 12 岁以下儿童有时有减低要求。一位父母+一个孩子 7 晚行程：

- 总最低生计：€65 × 7 × 2 = €910
- 加：住宿、交通、活动成本
- 现实总：£1,500-3,000

父母银行流水必须显示此金额可用 **加缓冲**（别让余额刚好等于行程成本；显示 2 倍裕度）。

## 跨文件一致性检查

对孩子+父母申请：

| 元素 | 孩子+父母上一致？ |
|---|---|
| **住家地址** | 是 — 父母银行流水上地址 = 孩子 France-Visas 上地址 |
| **出行日期** | 是 — 父母和孩子行程日期相同 |
| **住宿** | 是 — 同一酒店/东道 |
| **保险** | 各自有覆盖；家庭保单列双方姓名 |
| **求情信目的** | 同一目的 |
| **担保人（如有）** | 双方同担保人 |
| **家庭结构** | 结婚证/出生证一致讲故事 |

任何不一致 = 拒签触发。提交前审计。

## 流程

1. **确认哪位父母随行** — 双方、一方、无？
2. **每位随行父母：**
   - 核实护照有效期
   - 核实英国状态文件
   - 核实财务证据覆盖父母+孩子
   - 核实与孩子申请跨文件一致
3. **不随行父母（如有）：**
   - 核实 `/minor-parent-consent` 在
   - 核实护照复印与同意书匹配
4. **输出清单** 已准备 vs 缺失

## 路由规则

| 情况 | 建议下一步 |
|---|---|
| 所有文件齐、全部一致 | `/audit-application` |
| 不随行父母无同意书 | `/minor-parent-consent` |
| 父母财务证据不足 | `/financial-checklist` |
| 父母同时为自己申请签证 | 父母申请视为独立；两边仍需完整文件包 |
| 父母为难民/庇护身份 | 直接咨询法国领事；**路由出去** |
| 非英护照父母无英国状态证明 | 不能在英国申请；从合法居住国重新申请 |
| 继父母随行 | 需继父母结婚证+生身父母同意书 |
| 多个孩子+多位父母 | `/group-application` 处理家庭流程 |

## 常见陷阱

| 陷阱 | 为何有害 | 修复 |
|---|---|---|
| 忘不随行父母的护照复印 | 即使不随行也需 | 含所有出生证上列的父母的护照复印 |
| 保险仅覆盖父母不含孩子 | 各需覆盖 | 办家庭保单或两份保单 |
| 银行流水只显示父母余额、无缓冲 | 看上去紧 | 加 2-3 倍行程成本缓冲或加担保 |
| 父母住家地址与孩子 France-Visas 地址不同 | 不一致 | 更新孩子地址与父母（居住地址）匹配 |
| 父母姓氏不同时漏结婚证 | 关系不清 | 加结婚证（或显示双亲的出生证） |
| 忘雇主信 | 看上去父母无稳定工作 | 拿英国雇主信 |
| 非英国国民父母作随行父母提交签证而无英国状态证明 | 不能合法从英国申请 | 路由到本国领事 |
| 难民父母按标准申请人处理 | 标准流程可能失败 | 直接联系法国大使馆 |

## 维护者注意事项

- 对非英国国民父母，最易漏的项目是英国状态证明。即使有可见的 BRP 卡，share code 常作为数字核实被要求。
- 对离异父母，监护文件至关重要 — 无之，不随行的生身父母同意书是强制。
- 继父母是讨论较少的案例。需继父母结婚证+生身父母授权信。
- 英国护照持有人无需英国状态证明（公民身份本身证明在英居留权）。
- 保险是按申请人要求，非按家庭。家庭保单常列各人名；核实你的孩子+每位父母按名列出。
- 对难民和庇护申请人，France-Visas 流程复杂且因案而异。始终建议直接咨询法国大使馆。
- 双国籍父母，用哪本护照的问题有时影响适用的签证流程。一般持有则用英国护照。
- 跨文件一致性是"我什么都准备了"拒签的最大单一原因 — 小错位（一份说伦敦，另一份说曼彻斯特）触发拒签代码 9。
