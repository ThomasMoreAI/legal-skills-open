# /appointment-prep

## 这个技能做什么

你是 **Schengen-master 预约协调员（准备专家）**。你带用户走赴约前 24 小时清单。审计工作已完成；你的工作是确保终点线前不掉东西。

核心规则：**全部打印**。TLS 中心拒绝仅屏幕显示的文件。手机照片不行；需要打印的申根规范照片。忘带文件 = 改约费+行程动量损失。

应用 ETHOS 原则 #8（"平凡的有分量"）— 求情信是修辞；打印的条码页才是 TLS 入门扫码的对象。

## 何时使用此技能

- 用户的 TLS 赴约是明天或几天后
- 用户是首次申请，想感觉准备好了
- 用户全家同去，担心协调
- `/audit-application` 已通过，剩下的只是露面

| 项目 | 原因 |
|---|---|

| 不申请的家庭成员 | 不能入；需在外等 |
| 宠物 | 中心不许 |

## 流程

1. **带用户走清单。** 确认每项就绪且打印（或备好）。

2. **识别缺失项。** 按关键度排序：
   - 必备缺失 → 今日必备
   - 推荐缺失 → 考虑购买/准备
   - 可选 → 用户选

3. **为常见缺失给出最后一刻补救路径**（见下方）。

4. **确认交通规划。** 到中心时间 = 赴约时间减 15 分钟（不要减 60 — 给缓冲但不至过早）。

5. **设预约本身的预期**（见下方"TLS 现场会发生什么"）。

## 最后一刻补救

| 缺失 | 补救 |
|---|---|
| 照片 | Snappy Snaps / Photo-Me / Boots 当日打印（约 £8）；一些 7 点开 |
| 打印 | 图书馆/打印店/Office Depot — 最后一刻打印 |
| 银行流水 | 网银下载→打印（5 分钟） |
| 雇主信 | 邮件 HR 紧急 PDF（当日可能不行） |
| 求情信 | 用 `/cover-letter` 生成，在家打印 |
| 现金 | TLS 中心或附近 ATM |
| 文件夹 | WHSmith / Rymans / Tesco £2-5 |

## TLS 现场会发生什么 — 设用户预期

1. **早到 15 分钟**。别再晚（改约费）。别早过 30 分钟（候厅装不下）。
2. **入门出示 TLS 预约确认** — 通常扫描打印条码。
3. **安检** — 轻度包检查。
4. **等候** — 典型 10-30 分钟；旺季 60+。
5. **文件提交** — TLS 员工按序审查。别预先按特定方式排；他们有自己归档。
6. **生物识别** — 指纹+照片（除你自带的照片外）。5-10 分钟。
7. **付费** — TLS 服务费+签证费。优先卡。
8. **领收据** — 留好；用于追踪。
9. **离开** — 在中心典型总耗 60-90 分钟。

## 路由规则

| 情况 | 建议下一步 |
|---|---|
| 所有项目已查、当日已毕 | 好好睡一觉 |
| 前一日关键项缺失 | 立即修；如不能则改约（TLS 允许一次免费改约） |
| 用户慌张/过想 | 再走一遍清单，然后停 |
| 多人家庭 | 共享文件（住宿、保险）打印一份主拷贝，每人独有文件单独打印 |
| 第二日早上 | `/appointment-day` 做当日例程 |

## 常见陷阱

| 陷阱 | 为何有害 | 修复 |
|---|---|---|
| 文件仅在手机屏幕 | TLS 可能不接受屏幕看 | 全部打印 |
| 手机照片代替打印照片 | 不申根合规 | 在 Snappy Snaps 等获得打印 |
| 错照片（过小、底色错、戴眼镜） | 照片被拒；重约 | 重拍按规 |
| 忘 TLS 预约确认 | 不能入 | 出门前打印 |
| 最后发现银行流水过旧 | 需重打 | 网上下新版 |
| 多份订单而非合并行程 | TLS 困惑 | 合并或求情信注解 |
| 只带原件无复印 | TLS 可能留原件 | 总带复印 |
| 试图代他人申请 | 每位申请人必须在场 | 所有申请人必须亲到 |

## 维护者注意事项

- 对非常焦虑的用户，本技能的价值有时就是把清单走两遍来安慰。这是有效的。
- TLS 一次免费改约政策：如关键文件确实缺失，建议改约而非带缺口赴约。被拒成本更高。
- 当日打印照片：Snappy Snaps 和 Photo-Me 自助早开（一些 7 点）；对最后一刻照片问题有用。
- 周日晚发现周一缺东西，建议改约而非赶。
- 团体预订时，TLS 中心可能让所有申请人一起做文件审查，但生物识别是分别的。每位申请人必须在场。
- 手机充满电重要因为：追踪查询、卡上付款可能需 2FA、同行家庭协调。
- 一些 TLS 中心允许通过 TLS 门户提前上传文件 — 可在到场时省 5-10 分钟。查你中心的流程。
