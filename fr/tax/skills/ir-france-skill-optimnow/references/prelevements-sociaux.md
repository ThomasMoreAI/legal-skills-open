## Vue d'ensemble {#vue-ensemble}

Les prélèvements sociaux comprennent la CSG, la CRDS et le prélèvement de solidarité.
Ils s'appliquent en plus de l'IR sur la plupart des revenus.

---

## Revenus d'activité {#activite}

### Salaires
- CSG : 9,2 % (dont 6,8 % déductible)
- CRDS : 0,5 %
- Assiette : 98,25 % du salaire brut (abattement de 1,75 % pour frais professionnels)
- Prélevés à la source par l'employeur, pas de déclaration séparée

### Revenus des indépendants (TNS)
- CSG/CRDS calculées et prélevées par l'Urssaf
- Assiette : revenu professionnel + cotisations sociales Madelin
- Le traitement est fait au niveau des cotisations sociales, pas sur la déclaration IR

## Revenus du patrimoine {#patrimoine}

### Taux global : 17,2 %

| Composante                    | Taux   |
|-------------------------------|--------|
| CSG                           | 9,2 %  |
| CRDS                          | 0,5 %  |
| Prélèvement de solidarité    | 7,5 %  |
| **Total**                     | **17,2 %** |

### Revenus concernés
- Revenus fonciers
- Revenus de capitaux mobiliers (si option barème)
- Plus-values mobilières et immobilières
- Plus-values sur crypto-actifs

### Modalités de paiement
- Revenus fonciers et mobiliers (option barème) : appel de prélèvements sociaux
  par l'administration après déclaration, inclus dans l'avis d'imposition
- PFU : les 17,2 % sont inclus dans les 30 % prélevés à la source
- Plus-values immobilières : prélevées par le notaire
- Plus-values mobilières : prélevées par l'intermédiaire financier (acompte)
  puis régularisées via la déclaration

## Revenus de remplacement {#remplacement}

### Pensions de retraite
Taux de CSG variable selon le RFR :
- Exonération totale si RFR < seuil 1
- Taux réduit de 3,8 % si RFR entre seuil 1 et 2
- Taux médian de 6,6 % si RFR entre seuil 2 et 3
- Taux normal de 8,3 % si RFR > seuil 3

CRDS : 0,5 % dans tous les cas (sauf exonération totale)

Les seuils dépendent du nombre de parts et sont mis à jour annuellement.
Vérifier les seuils dans le barème officiel.

### Allocations chômage
- CSG : 6,2 % (dont 3,8 % déductible)
- CRDS : 0,5 %
- Exonération si l'allocation nette serait inférieure au SMIC

## CSG déductible {#csg-deductible}

### Principe
Une fraction de la CSG payée est déductible du revenu imposable de l'année de paiement.

### Taux déductibles par catégorie de revenu

| Catégorie                     | CSG totale | CSG déductible |
|-------------------------------|------------|----------------|
| Salaires                      | 9,2 %      | 6,8 %          |
| Revenus du patrimoine         | 9,2 %      | 6,8 %          |
| Pensions (taux normal)        | 8,3 %      | 5,9 %          |
| Pensions (taux médian)        | 6,6 %      | 4,2 %          |
| Pensions (taux réduit)        | 3,8 %      | 0 %            |
| Allocations chômage           | 6,2 %      | 3,8 %          |

### Conditions pour la CSG sur revenus du patrimoine
La CSG est déductible uniquement si l'option barème est choisie (case 2OP).
En cas de PFU, la CSG n'est pas déductible.

### Case
- **6DE** : CSG déductible sur les revenus du patrimoine
- Pour les salaires et pensions : la déduction est automatique (intégrée dans le net imposable)

## Cas des non-résidents et résidents EEE {#non-residents}

### Résidents EEE affiliés à un régime de sécurité sociale étranger
Les revenus de source française (fonciers, plus-values immobilières) de personnes affiliées
à un régime social d'un État de l'EEE ou de la Suisse sont :
- Exonérés de CSG et CRDS
- Mais soumis au prélèvement de solidarité de 7,5 %

Cette exonération résulte de la jurisprudence "de Ruyter" (CJUE) et de ses suites législatives.

### Non-résidents hors EEE
- Prélèvements sociaux de 17,2 % sur les revenus de source française
- Pas d'exonération possible
